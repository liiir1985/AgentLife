# 记忆系统设计

## 1. 文档目的

本文定义记忆系统的产品级模型、职责边界和运行语义。记忆系统把角色实际获得并处理的信息组织为有限的工作记忆、近期记忆和长期记忆，维护角色对实体形成的主观认识，并通过受限的混合检索为认知提供相关而不保证完整、准确的回忆。

本文不把世界客观历史视为角色记忆，不要求角色保存全部经历，也不固定具体数据库、向量索引、嵌入模型、提示词、类结构或协议字段。语义相似度是必需能力，但其提供器和存储实现可以替换。

第一阶段只要求完整 AI 角色关联记忆实例。用户角色可以继续采用简化代理模型；这一内部差异不能使其他角色绕过正常感知和记忆流程认识用户角色。

## 2. 设计目标

记忆系统需要保证：

* 记忆只能来源于角色实际获得并进入 Working Memory 的观察、理解、反思和决定。
* Working Memory、Recent Memory 和 Long-term Memory 具有不同容量、时间和遗忘语义。
* Working Memory 有确定性容量上限、快速衰减和真实删除；退出不等于形成持久记忆。
* Recent Memory 没有容量上限，以近期时间窗口管理；超窗未巩固内容从运行时永久删除。
* Long-term Memory 由 Recent Memory 巩固形成，不在两个活动层保存同一份运行时副本。
* 每个角色分别维护对人物、物品、地点及其他可识别实体的主观档案。
* 世界事实、当前感知、主观实体知识、情景记忆和审计记录严格分离。
* 相关性与可达性分别计算；高度相关的线索可以激活较难想起但仍存在的记忆。
* 混合检索结合结构索引、关联图、语义相似度、当前情境和受限 Agent 重排。
* 已删除内容和审计归档不能通过语义检索、实体关联或 Agent 调用重新进入角色记忆。
* 编码、检索、巩固、删除和档案更新在稳定模拟边界顺序执行并原子提交，不产生异步状态分叉。

## 3. 职责边界

### 3.1 记忆系统负责

记忆系统负责：

* 维护每个 AI 角色独立的 Working、Recent 和 Long-term Memory。
* 对进入 Working Memory 的认知块执行容量求值、准入、替换、使用确认和快速衰减。
* 验证认知 Agent 提交的编码候选并形成 Recent Memory 痕迹。
* 在明确稳定边界调度记忆 Agent 完成巩固，并验证、提交长期结果。
* 维护记忆痕迹的结构索引、关联图、语义表示、可达性和抑制状态。
* 验证 Retrieval Intent，生成候选，计算相关性与综合激活，并组织受限重排。
* 维护观察者私有的主观实体档案、实体识别关联及其来源。
* 为感知系统提供最小主观身份关联查询，为认知提供受限 Memory Skill。
* 为认知系统拥有的前瞻性意图提供可复用的结构索引、语义表示、相关性、可达性和 Working Memory 准入基础能力，而不接管意图状态。
* 对运行时删除和巩固来源移除执行受保护审计归档。
* 保存和恢复记忆状态、索引版本、未完成操作及幂等身份。

### 3.2 记忆系统不负责

记忆系统不负责：

* 维护世界 Ground Truth、客观事件历史、身体状态或人物真实身份。
* 决定角色实际感知到什么，或把候选刺激当作已经获得的经历。
* 维护认知系统的注意、疑问、前瞻性意图、持续性决定或完整 LLM Context。
* 替认知 Agent 竞争或选择当前应追随的意图。
* 把用户输入、模型原始响应、隐藏推理、控制来源或诊断追踪写入角色记忆。
* 因为世界实体 ID 相同就强制角色认出实体。
* 让记忆 Agent 查看完整记忆库、审计归档或未通过召回门槛的候选。
* 直接修改人物 Identity、世界事实、身体状态或感知结果。
* 使用现实墙上时间推进遗忘、巩固或索引状态。
* 在必要记忆处理失败时静默退化为“角色没有想起来”。

## 4. 信息与状态分层

### 4.1 记忆材料

记忆材料是已经提交并允许进入记忆流程的观察、认知理解、反思和决定。材料必须带有角色归属、模拟时间、来源类型和依赖版本。

客观世界事件、候选刺激、被过滤感知材料、完整模型响应和调试记录都不是普通记忆材料。

### 4.2 Working Memory 认知块

Working Memory 认知块是认知当前可以直接使用的有限信息单元，可以包含当前观察、刚形成的认知内容或对持久记忆痕迹的激活引用。

认知块不是按自然语言长度或 Token 数切分的文本片段。每个认知块具有明确类型、来源、负荷、进入时间、最近使用时间、保持状态和当前生命周期。

### 4.3 记忆痕迹

记忆痕迹是选择性编码后形成的持久主观记录。痕迹保存角色当时获得或形成的内容、来源类别、模拟时间、主观视角和后续索引所需信息，不等同于客观事件副本。

### 4.4 主观解释

主观解释表示角色对痕迹形成的理解、评价或判断。不同解释可以相互支持、冲突或修正。后续新判断可以改变解释的可达性和当前倾向，但不能把过去没有感知到的事实伪装成原始痕迹。

这里的“主观解释”仅指已经通过正常编码形成的持久痕迹或断言。认知在一次调用内对若干记忆片段进行的临时补全、联想和解释不构成独立记忆对象，也不需要单独的回忆重建 Agent；只有认知明确提交新的反思、判断或关系认识并通过来源验证后，才会形成新的 Recent 痕迹。

### 4.5 关联图

关联图连接角色实际形成的痕迹、解释、主观实体档案和长期模式。关联可以表达同一经历、共同实体、共同地点、前因后果、后续反思、支持、冲突或修正。

关联必须具有来源，不能连接隐藏世界事实或其他角色私有状态。

### 4.6 语义表示

语义表示是供相关性检索使用的受保护索引产物，不是角色自己知道的数值或概念列表。每个表示关联原始运行时痕迹、生成配置版本和语义提供器版本。

### 4.7 Activation Set

Activation Set 是一次检索中已经通过权限、状态和综合激活门槛的有限候选集合。它尚未等于角色已经想起的内容；只有进一步通过 Working Memory 容量准入的片段才能进入认知。

### 4.8 审计归档

审计归档保存已从运行时记忆删除的内容及其删除、巩固和索引操作记录。归档只服务授权调试和一致性审计，不属于角色记忆，也不参与任何运行时索引。

## 5. Working Memory

### 5.1 权威边界

Working Memory 由记忆系统维护，表示认知当前可直接使用的信息。认知系统仍独占注意、主观理解、疑问、前瞻性意图和持续性决定；两者不能保存相互竞争的权威副本。Working Memory 可以保存对获准意图候选的激活引用，但不能复制、修改或延长对应意图的生命周期。

所有新观察、认知产物和检索结果必须先进入 Working Memory，才能被认知使用或被编码为持久记忆。

### 5.2 容量模型

每个认知块默认占用一个容量单位。配置可以按明确的认知块类型设置小范围离散权重，但不能依据自由文本长度、LLM 自报难度或隐藏语义复杂度给出负荷。

Working Memory 总容量及身体、认知状态造成的修正由统一配置与规则基础设施确定性求值。未声明特殊权重时统一使用默认单位。

总容量中可以为前瞻性意图激活引用预留少量配置化容量。预留只保证相关意图拥有受限入口，不增加总容量，也不允许意图无限挤出当前观察；未被意图候选使用的预留容量是否回到一般池必须由配置明确并保持确定性。

### 5.3 准入与替换

候选认知块进入前必须验证来源、归属和状态版本，再依据当前容量执行准入。一般候选容量不足时，系统根据注意关联、显著度、当前使用状态、时效和显式保持标记确定性计算替换优先级，并移出最低优先级内容。意图激活引用超过预留容量时，由认知系统提供的相关性、可达性、承诺度和时效作为显式输入稳定裁剪；该裁剪不能把任何候选宣布为角色应追随的意图。

保持标记只提高优先级，不提供无限容量或绝对不可替换权。容量下降时在下一个稳定边界重新求值并收缩；容量恢复不会自动找回已经删除的内容。

### 5.4 使用确认

认知引用某个认知块、用它形成判断或明确持续关注时，应在认知提交后确认实际使用。仅进入 Working Memory、被查询命中或被模型输入读取但没有成为已提交认知的一部分，不自动视为已使用。

### 5.5 快速衰减与真实删除

Working Memory 使用远快于 Recent Memory 时间窗口的模拟时间衰减。实际使用可以刷新认知块的保留状态；始终未使用的内容更快到期。

未编码认知块到期后从 Working Memory 真实删除，不转入 Recent Memory。已经编码或由检索激活的认知块到期时只删除激活引用，不影响对应持久痕迹。

## 6. Recent Memory

### 6.1 选择性编码

即时编码发生在本轮认知实际使用之后、Working Memory 到期处理之前。认知 Agent 从实际处理过的认知块中明确提交编码候选。

记忆系统验证候选已经合法进入 Working Memory、属于当前角色、来源于已提交观察或认知内容、不包含禁止信息，并且不会重复编码同一经历。成功后生成 Recent 痕迹，同时建立结构索引、关联和语义表示。

Working Memory 随后只保留该痕迹的激活引用。检索旧记忆本身不会生成新的 Recent 痕迹；围绕旧记忆形成的新反思可以作为新材料编码。

### 6.2 近期时间窗口

Recent Memory 不设置容量上限，只设置可配置的近期时间窗口。窗口内痕迹可以参与近期检索、实体档案支持和巩固候选选择。

### 6.3 到期遗忘

痕迹到期时先检查它是否已经巩固、正在参与巩固或由明确有效条件保护。未巩固且不再受保护的痕迹从运行时永久删除，并写入审计归档。

删除后的痕迹不参与结构索引、关联图、语义索引、可达性计算、实体档案物化或 Agent 输入，也不能被任何强线索重新激活。

## 7. Long-term Memory 与巩固

### 7.1 巩固触发

巩固可以由模拟时间、近期窗口即将结束、已提交的睡眠或休息状态、待处理痕迹数量或其他明确配置条件触发，但系统不硬编码必须睡眠。

### 7.2 确定性准备

巩固开始前，确定性系统固定候选痕迹、来源权限、记忆版本、配置版本和调用预算。候选之外的记忆、审计归档和世界 Ground Truth 不得进入记忆 Agent 上下文。

### 7.3 记忆 Agent 职责

记忆 Agent 可以识别重复经历和长期模式，判断值得保留的内容，形成长期情景、知识、关系印象、经验或习惯线索，并概括冲突、不确定性和角色的主观解释。

记忆 Agent 只能生成候选结果，不能直接修改运行时状态、人物 Identity 或世界事实。

### 7.4 提交语义

单条重要 Recent 痕迹可以通过状态迁移成为 Long-term 痕迹，不产生副本。多条 Recent 痕迹可以归纳为新的长期记录；系统必须先原子提交长期结果，再从运行时删除来源痕迹并写入审计归档。

巩固允许摘要、偏差、错误和信息丢失，不要求长期结果能够恢复全部近期细节。长期提交、来源删除或归档任一步骤失败时，不能留下已经删除来源但没有长期结果的状态。

### 7.5 与 Identity 的边界

巩固可以形成习惯、偏好或自我认识变化所需的经历模式，但不能直接修改人物 Identity。认知系统可以基于这些长期模式提出 Identity 候选变化，再由人物系统验证和提交。

### 7.6 人物背景与初始记忆

Identity 中的人物小传、个人历史和自我定义属于人物配置与认知背景，不会因为创建记忆实例而自动拆分为情景记忆、知识痕迹或主观实体档案。未经专门提取、来源标注和领域验证的背景文本不能作为 Memory Skill 的独立候选，也不能伪装成角色已经实际回忆起的经历。

第一阶段创建记忆实例时不隐式生成模拟开始前的 Long-term Memory。未来可以设计独立工具，从人物小传、对话记录或详细资料中提取初始记忆与实体档案候选；该工具及其导入语义不在本文展开，任何结果仍必须经过记忆领域验证后才能进入运行时。

## 8. 主观实体档案

### 8.1 适用范围

每个记忆实例分别维护自己的主观实体档案。统一模型适用于人物、物品、地点和世界配置允许识别的其他实体，不同实体类型只开放对应的合法主观断言类型。

### 8.2 档案内容

档案可以包含主观名称、称呼、别名、实体类别、长期属性、行为模式、印象、评价、关系判断、共同经历引用、冲突断言以及当前首选断言和主观确信程度。

档案中的内容是观察者相信或倾向相信的内容，不是世界事实，可以错误、冲突、缺失或过时。

### 8.3 物化视图与来源

主观实体档案是记忆痕迹之上的物化索引视图，不是第四种记忆层。每条断言必须由仍存在的 Recent 或 Long-term 痕迹支持。

新的名称、属性或关系判断必须由认知 Agent 明确提交，并引用当前 Working Memory 中的观察、陈述、推测或回忆来源。记忆系统不能因为听见某个声明就自动替角色接受它。

### 8.4 来源失效

支持断言的 Recent 痕迹到期删除时，如果没有其他有效支持，相关档案断言同步失效；如果已经巩固，断言改由 Long-term 结果支持。

冲突断言可以并存。当前首选断言由支持痕迹、主观确信、可达性及明确规则共同决定，不能静默覆盖历史判断。

### 8.5 当前表现与长期属性

当前观察到的衣着、姿态或状态属于感知结果和 Working Memory；一次过去外观可以成为 Recent 情景记忆；只有经过多次经历巩固形成的“经常如此”等模式才作为长期主观属性进入档案。

实体档案中的过时属性不能覆盖感知系统对当前世界表现形成的观察。

## 9. 实体识别

### 9.1 不透明实体锚点

世界材料中的实体 ID 只作为受保护的不透明锚点，用于感知连续追踪和记忆内部定位识别关联。实体 ID 不是角色知道的名称，不贡献识别置信度，也不能被认知 Agent 用于查询世界状态。

认知侧只能获得观察者本地的主观档案引用。第一阶段原则上为一个观察者的一个实体锚点维护一个活动档案；复杂身份合并、拆分和冒充推理不在本阶段范围内。

### 9.2 感知分辨率

感知系统依据光线、距离、遮挡、感官效率、注意、连续观察及配置化伪装修正确定性计算感知分辨率。

极低分辨率只能形成实体轮廓或人影；中等分辨率可以形成配置允许的类别、体型、衣着和相对位置；较高分辨率可以形成更完整的外在描述，并允许尝试身份识别。

这些描述来自当前世界感知投影，不来自主观实体档案。

### 9.3 身份识别置信度

只有达到可尝试识别的分辨率后，才依据当前分辨率、识别关联强度和可达性、连续观察、遮蔽、伪装及其他配置修正确定性计算身份识别置信度。内部实体 ID 本身不能增加分数。

低于识别阈值时，记忆系统不返回档案，只保留当前分辨率允许的模糊描述。达到阈值时，只返回观察者本地档案引用、当前首选称呼和识别置信度。

普通换装只改变当前描述；只有明确配置的遮蔽、伪装或辨认修正降低置信度。结构化结果保留确定性数值，向认知渲染时同时提供自然语言等级。

### 9.4 最小查询边界

感知系统的身份关联查询只能接收观察者、不透明实体锚点、感知分辨率、辨认修正、连续观察状态和依赖版本。

该查询不能返回完整实体档案、共同经历、关系背景、世界真实身份、其他角色的档案或审计归档内容。认知需要更多背景时必须通过 Memory Skill 按需检索，并接受 Working Memory 容量约束。

### 9.5 识别遗忘与重连

实体锚点与档案之间的识别关联具有独立可达性。关联衰减后，即使档案仍存在，感知也可能只返回陌生实体及当前外在描述。

旧档案仍可以通过称呼、地点或共同经历等其他线索被检索。认知判断当前实体与旧档案相同后，可以提交重新关联候选；记忆系统验证当前观察和旧记忆来源后才恢复关联，不能仅因语义相似自动重连。

## 10. Retrieval Intent

### 10.1 记忆查询

认知 Agent 通过受限 Memory Skill 提交开放式查询。系统把查询组织并验证为 Retrieval Intent，可以包含：

* 自然语言语义查询。
* 观察者本地实体档案引用。
* 主题或概念线索。
* 时间范围或相对时间。
* 地点、活动和事件类型。
* 关系、参与对象和主观立场。
* 期望的记忆类型。
* 当前 Working Memory、注意和意图提供的上下文。

Retrieval Intent 不能包含世界实体 ID、审计记录标识、其他角色的私有记忆引用或未经授权的世界事实。

同一认知轮次可以在明确预算内根据初次结果调整查询并再次调用 Memory Skill。调用次数和候选规模必须有上限，不能由 Agent 无限检索直到满意。

### 10.2 前瞻性意图召回接入

前瞻性意图由认知系统拥有，不属于 Retrieval Intent 查询目标或记忆痕迹。认知系统可以复用本系统的结构索引、语义表示、相关性、可达性和稳定去重能力，对当前角色仍存在的未完成意图形成有限候选。

意图召回必须使用独立类型和索引命名空间，不能与情景记忆、主观知识或实体档案混合成同一结果。记忆系统只返回分数、候选和 Working Memory 准入结果，不能改变意图生命周期、解释主观承诺度、执行意图竞争或决定行动。意图候选只有通过预留容量后才作为明确标注的激活引用进入认知。

## 11. 相关性模型

### 11.1 相关性与可达性分离

相关性回答某条记忆与本次查询是否匹配；可达性回答该记忆当前有多容易被想起。两者必须分别计算和追踪。

### 11.2 精确结构关联

结构索引可以匹配主观实体档案引用、地点、参与者、活动、时间范围、事件类型、记忆类型、关系类别、来源类别以及已知冲突或修正关系。

明确结构条件可以作为硬过滤器或高强度查询线索，但不能提升调用者权限。

### 11.3 关联图相关性

检索可以沿具有来源的记忆关联扩展候选。扩展深度、边类型和影响上限必须由配置限制，避免无界联想把大量弱相关内容带入候选集。

### 11.4 语义相似度

语义相似度是第一阶段必需能力。系统对授权的运行时记忆内容和查询生成语义表示，并计算开放语义匹配程度。

默认实现可以使用嵌入表示，但产品语义不绑定具体模型、向量数据库或存储方案。小规模世界可以直接比较表示，规模扩大后可以替换索引实现。

语义相似度具有配置化上限，不能单独绕过角色归属、状态过滤、审计隔离或可达性机制。已经删除或进入审计归档的内容不产生运行时语义候选。

### 11.5 当前情境匹配

当前 Working Memory、注意、意图、观察实体、地点、未解决问题和明确回忆目的可以形成查询上下文。当前情境只提供线索，不能修改记忆内容或访问权限。

### 11.6 相关性组合

查询相关性由结构命中、关联路径、受限语义相似度和当前情境匹配共同形成。具体组合方式、权重、上限和缺失输入处理由统一规则基础设施配置并确定性求值，不固定为某个数学公式。

## 12. 线索激活与召回

### 12.1 候选生成

检索首先执行角色归属、状态和权限过滤，再通过结构索引、关联图和语义索引分别生成候选并稳定去重。

### 12.2 综合激活

每个候选分别计算查询相关性、基础可达性和冲突抑制、主动压制等抑制项，再形成综合激活。概念关系为：

**综合激活 = 基础可达性 + 查询相关性 - 抑制**

具体运算和组合规则由配置决定。只有超过召回阈值的候选才能进入有限候选集。

该模型允许高度吻合的实体、地点或事件线索激活较低可达但仍存在的记忆，同时阻止高可达但无关、强烈受抑制或已经删除的内容进入结果。

### 12.3 受限语义重排

只有通过权限和综合激活门槛的有限候选可以交给记忆 Agent。记忆 Agent 可以按当前查询意义重排、选择和组织候选，但不能查看完整记忆库、恢复门槛以下内容、访问审计归档、修改来源或创造不存在的记忆。

重排输出需要再次验证候选身份和来源，再形成 Activation Set。重排只组织既有候选，不负责把片段重建成完整主观回忆，也不产生供认知二次决策的独立叙事对象。

### 12.4 Working Memory 准入

Activation Set 中的结果仍需参加 Working Memory 容量竞争。检索命中不保证角色想起；只有成功进入 Working Memory 的有限片段才能提供给认知 Agent。

### 12.5 消费强化

认知确认实际使用某个检索结果并完成提交后，才强化对应痕迹、实体断言或识别关联。试探查询、候选生成、重排淘汰和未进入 Working Memory 的结果不产生强化。

认知正式提交相冲突的新判断时，新解释可以得到强化，旧长期解释受到抑制，但仍存在的长期痕迹不自动删除。

## 13. 语义能力版本与配置

语义相似度提供器是可替换的领域能力。运行配置必须标识语义模型、表示版本、相似度策略和兼容要求，但不要求使用特定供应商。

每条语义表示记录生成它的配置和提供器版本。一次检索只能组合兼容的表示；更换不兼容模型时必须显式重建索引或执行迁移，新旧分数不能静默混合。

重建语义索引只能改变索引产物，不能改变原始记忆内容、来源、可达性、关联或实体档案断言。语义提供器失败属于记忆处理失败，不能静默解释成角色自然遗忘。

## 14. 遗忘、冲突与主观确信

Working Memory 使用快速衰减和真实删除。Recent Memory 在时间窗口内可以降低可达性，但超窗未巩固时最终退出运行时。Long-term Memory 主要通过可达性和抑制表达淡忘。

系统保留痕迹来源类别，角色认知自行形成主观确信。角色可以确信错误或经过巩固而失真的记忆；系统来源质量不能直接替角色判断真假，也不能被抹去后伪装成亲历证据。

后续新判断可以显著抑制冲突的长期解释。只要旧长期痕迹仍存在，高度相关的新线索就可能重新激活它；已经因 Recent 到期或巩固来源移除而进入审计归档的内容不能重新激活。

## 15. 审计归档

审计归档保存到期删除的 Recent 痕迹、巩固后移除的来源、随来源失效而移除的实体断言，以及相关模拟时间、配置版本、操作身份和原因。

归档不参与结构索引、语义索引、关联图、实体识别、相关性、可达性、巩固或提示构建。运行时组件不能因为知道归档身份而读取其内容，保存恢复也不能把归档重新加载为角色记忆。

归档保留期限和管理清理属于运维设计，不改变角色记忆语义。

## 16. 更新顺序与调度边界

一个需要记忆参与的稳定模拟边界按以下产品级顺序处理：

1. 世界、身体和感知系统提交本时间点结果，感知生成结构化观察和当前外在描述。
2. 达到条件时执行最小主观身份关联查询。
3. 观察候选参加 Working Memory 容量准入。
4. 认知系统按当前情境生成相关未完成意图候选，候选参加 Working Memory 预留容量准入。
5. 认知 Agent 根据当前情境有限多轮调用 Memory Skill。
6. 记忆系统执行权限过滤、混合候选召回和线索激活。
7. 对有限记忆候选执行受限语义重排，Activation Set 参加 Working Memory 一般容量准入。
8. 同一次认知 LLM 调用读取 Identity、观察、意图激活引用和带来源记忆片段，在调用内完成片段解释、意图权衡和行动决定。
9. 认知提交认知状态、意图变化、身体计划、记忆消费确认、编码候选和实体档案断言候选。
10. 认知系统提交意图变化；记忆系统提交 Recent 编码、索引、强化和档案更新。
11. 执行本边界到期的记忆巩固。
12. 依次处理意图衰减与 Working Memory 快速衰减。
13. 处理 Recent 到期删除和审计归档。
14. 原子提交完整状态后，整体模拟才允许继续。

记忆处理不与世界时间推进异步分叉。现实计算可以用于缩短单个处理阶段的等待，但其结果必须基于固定快照并在统一提交前保持不可见。

## 17. 跨系统协作

### 17.1 与世界系统

世界系统维护事实和客观事件历史。世界实体 ID 只以不透明锚点进入受限识别流程；Ground Truth 和审计历史不能作为普通记忆检索源。

### 17.2 与感知系统

感知系统提供已经提交的结构化观察、当前感知分辨率和受保护实体锚点。记忆系统提供最小身份关联结果，但不能反向补充当前未感知的实体属性或完整档案。

候选刺激、被过滤材料和中断期未获得的事件不能成为记忆材料。

### 17.3 与认知系统

认知系统通过 Working Memory 获得观察和回忆，通过 Memory Skill 提交 Retrieval Intent，并在决定提交时确认实际消费、提出编码候选和实体断言候选。

认知系统独占前瞻性意图状态及其主观生命周期决定，记忆系统只为意图召回复用索引、相关性、可达性和 Working Memory 准入能力。认知在同一次行动决策调用内解释获准记忆片段；临时解释不自动写回记忆，也不触发独立重建调用。

认知不能直接写入 Recent、Long-term、实体档案、可达性或索引，也不能访问世界实体 ID 和审计归档。

### 17.4 与人物系统

人物系统维护角色与记忆实例的归属关系，不读取或复制记忆内容作为 Identity。主观实体档案属于观察者的记忆实例，不属于被观察实体的人物 Identity。

Identity 中的人物小传和个人历史不自动成为 Long-term Memory。未来资料提取工具只能提交带来源候选，不能绕过记忆领域验证直接初始化痕迹。

### 17.5 与身体系统

身体系统可以通过认知参与许可和配置允许的状态修正影响 Working Memory 容量或记忆处理资格，但不能直接写入记忆内容。身体变化只有经过感知和认知链路后才可能成为经历。

### 17.6 与认知调度及整体时间

需要完成的检索、语义处理、编码、巩固、删除或归档属于当前稳定边界。必要处理未完成时，整体模拟不能推进到下一 Tick。

### 17.7 与统一配置与规则基础设施

共享基础设施提供容量、离散负荷、时间窗口、可达性、相关性组合、抑制、识别置信度、阈值、触发条件和版本验证的确定性求值能力。

共享基础设施只能产生候选分数和操作建议，不能提交记忆、运行 Agent、形成主观语义或访问审计归档。

### 17.8 与配置生成 Skill

配置生成 Skill 未来可以生成记忆类型、容量策略、索引策略、语义提供器引用、组合规则和触发配置。生成结果必须通过共享验证和记忆领域验证，不能预写具体角色的隐藏记忆或实体认识。

## 18. 产品级概念接口

以下接口定义产品责任，不规定字段或协议。

### 18.1 记忆实例创建与加载

建立角色独立记忆实例、空的 Working Memory、空的持久痕迹存储、实体档案索引和兼容的语义能力。人物 Identity 或背景文本不会在该接口中隐式生成初始记忆；缺少必需语义提供器或版本不兼容时不能进入运行。

### 18.2 Working Memory 候选提交

接收已提交观察或认知材料，执行来源验证、负荷求值、容量准入和替换，返回接纳、替换、拒绝或版本过时结果。

### 18.3 Working Memory 使用确认

在认知决定提交后确认实际使用的认知块，刷新合法保留状态并作为编码和检索强化的依据。

### 18.4 Recent 编码

接收认知提交的编码候选，验证 Working Memory 来源、权限、重复性和版本，原子建立痕迹、结构索引、关联和语义表示。

### 18.5 巩固处理

固定候选快照，调用记忆 Agent，验证长期结果，并原子完成状态迁移或长期结果提交、来源删除及归档。

### 18.6 主观实体断言提交

接收带 Working Memory 来源的名称、类别、属性、关系或印象候选，验证后更新物化档案和冲突关系。

### 18.7 最小身份关联查询

接收观察者、不透明锚点、感知分辨率、辨认修正和版本，返回未识别，或最小档案引用、首选称呼、数值置信度及自然语言等级。

### 18.8 Retrieval Intent 提交

验证开放式查询、观察者本地引用、结构线索、上下文和调用预算，拒绝世界实体 ID、审计身份和跨角色私有引用。

### 18.9 混合候选召回

执行状态过滤、结构检索、关联扩展、语义检索、相关性求值、综合激活及稳定去重，返回通过阈值的有限候选。

### 18.10 受限语义重排

把有限候选交给记忆 Agent 重排并验证输出。接口不能接受完整记忆库，也不能恢复过滤结果。

### 18.11 Activation Set 准入与消费

将重排结果提交 Working Memory 容量竞争，并在认知成功使用后确认消费和强化。

### 18.12 识别关联重连

接收认知基于当前观察和旧档案形成的重连候选，验证后恢复实体锚点关联。

### 18.13 语义索引管理

生成、核对、重建或迁移语义表示。索引操作不能修改原始记忆语义或静默混用不兼容版本。

### 18.14 运行时删除与审计归档

从全部运行时索引、关联和物化档案中移除到期内容，并把允许保留的数据写入受保护归档。删除和归档必须处于同一受控提交边界。

### 18.15 保存与恢复

保存 Working Memory、Recent、Long-term、实体档案、关联、可达性、抑制、索引版本、待处理操作及幂等身份。恢复不能重复编码、强化、巩固、删除或归档。

### 18.16 前瞻性意图召回接入

接收认知系统授权的未完成意图视图和当前情境，复用兼容的结构、语义、相关性及可达性能力生成有限候选，并将其提交 Working Memory 预留容量。接口不拥有意图、不改变生命周期，也不返回“获胜意图”或行动建议。

## 19. 失败与一致性语义

### 19.1 状态唯一

Working Memory、运行时痕迹、实体档案、关联和可达性由对应记忆实例维护唯一权威表示。索引和物化档案是受控派生状态，必须能与其来源版本核对。

### 19.2 版本一致

所有操作携带角色归属、模拟时间、记忆版本、运行配置版本和语义表示版本。过时结果不能覆盖当前状态。

### 19.3 原子提交

编码必须同时提交痕迹和必要索引；巩固必须先保证长期结果成立再移除来源；运行时删除必须同步移除全部可检索入口。失败不能泄漏部分状态。

### 19.4 效果不重复

保存恢复和重试不能重复编码、强化、巩固、档案更新、删除、归档或重连。

### 19.5 全部阻塞

记忆检索、意图召回接入、语义表示、重排、编码、档案更新、巩固、删除或归档任一必要步骤失败时，模拟保持在当前稳定边界。有限重试失败后进入可见错误状态，不能降级跳过，也不能把系统故障解释为角色遗忘或没有未完成意图。

## 20. 验收场景

1. 新观察必须先通过 Working Memory 容量准入，不能直接写入 Recent 或实体档案。
2. 不同认知块可以使用配置声明的离散负荷，LLM 不能自行指定负荷。
3. 容量不足时，高显著或正在使用的内容可以确定性替换低优先内容。
4. Working Memory 未使用内容会快速到期并真实删除。
5. 未编码 Working Memory 内容退出后不会自动形成 Recent Memory。
6. 已编码内容离开 Working Memory 时只删除激活引用。
7. 检索旧记忆不会生成重复 Recent 痕迹，新反思可以形成关联的新痕迹。
8. Recent Memory 不发生容量驱逐，只按时间窗口退出。
9. 超窗未巩固 Recent 从运行时删除后不能被任何线索或 Agent 重新检索。
10. 单条 Recent 提升为 Long-term 时只发生状态迁移。
11. 多条 Recent 巩固后只保留长期结果，来源仅在审计归档中存在。
12. 长期结果提交失败时不得提前删除 Recent 来源。
13. 高可达但与查询无关的记忆不会进入结果。
14. 高度吻合的实体、地点或事件线索可以激活低可达但仍存在的长期记忆。
15. 结构索引、关联图和语义索引生成的候选可以稳定合并和去重。
16. 语义相似度不能绕过角色归属、删除状态、来源权限或审计隔离。
17. 记忆 Agent 只能看到已经通过综合激活门槛的有限候选。
18. Agent 重排不能恢复门槛以下的痕迹或创造不存在的记忆。
19. Activation Set 超过 Working Memory 容量时，只有通过准入的部分被想起。
20. 未消费结果不会强化痕迹、档案断言或识别关联。
21. 语义模型版本不兼容时检索明确失败，不能混用分数。
22. 重建语义索引不会改变原始记忆、可达性和实体档案。
23. 第一次观察实体时，系统不能通过实体 ID 返回世界真实名称。
24. 角色听见实体自报姓名但未形成认知判断时，档案不会自动接受该姓名。
25. 两个角色可以对同一世界实体维护不同称呼、关系和主观属性。
26. 极低感知分辨率只能得到轮廓或人影，中等分辨率可以得到有限外在描述。
27. 识别置信度低于阈值时，即使内部实体 ID 相同也不能返回档案。
28. 识别成功只返回最小档案引用、称呼和置信度，不自动加载共同经历。
29. 普通换装不会创建第二档案，明确伪装或遮蔽可以降低识别置信度。
30. Recent 来源到期后，没有其他支持的实体断言同步失效。
31. 已巩固实体知识在 Recent 来源移除后继续由 Long-term 结果支持。
32. 识别关联衰减后，实体可以被视为陌生对象，而旧档案仍可通过其他线索检索。
33. 恢复识别关联必须由认知明确提交，不能由相似查询自动完成。
34. 审计归档不参与任何结构、语义、实体或可达性检索。
35. 保存恢复和失败重试不会重复编码、强化、巩固、删除、归档或重连。
36. 任一必要记忆步骤失败时，模拟时间保持不变且不产生部分结果。
37. 意图候选与记忆痕迹使用独立类型和索引命名空间，不会被当作过去事实返回。
38. 相关意图可以复用结构和语义召回，但记忆系统不能选择角色应追随哪条意图。
39. 意图激活引用使用 Working Memory 预留容量，且不会突破 Working Memory 总容量。
40. 记忆 Agent 的受限重排只能组织已有片段，不会生成独立主观回忆叙事。
41. 认知对记忆片段的临时解释不会自动成为 Recent Memory 或覆盖来源痕迹。
42. 新反思只有引用本轮实际消费片段并通过编码验证后才形成新的 Recent 痕迹。
43. Identity 人物历史不会在记忆实例创建时自动成为可检索的 Long-term Memory。
44. 认知、意图和记忆维护未按统一稳定边界完成时，整体模拟不会提前推进。

## 21. 范围边界

本文不定义：

* 具体角色的记忆内容、实体认识、关系、偏好或数值参数。
* 具体数据库、向量索引、嵌入模型、提示词全文、类结构或通信协议。
* 脸部、声纹、步态或自由文本外貌描述的生物特征匹配。
* 完整的身份合并、拆分、冒充和多对多身份假设。
* 梦境机制、完整神经认知模拟或客观真相自动判定。
* 用户角色的完整主观记忆实例。
* 人物小传、对话记录或详细资料到初始记忆和实体档案候选的提取工具。
* 审计归档的运维保留期限和管理清理策略。

## 22. 设计约束总结

1. 所有新信息必须先进入 Working Memory，才能被认知使用或编码。
2. Working Memory 有确定性容量、快速衰减和真实删除，不等于完整认知上下文。
3. Recent Memory 没有容量上限，以时间窗口管理；超窗未巩固内容退出运行时。
4. Long-term Memory 由 Recent 巩固形成，不保留活动层双份副本。
5. 主观实体档案是带来源的记忆物化视图，不是世界事实或独立记忆层。
6. 实体 ID 只是不透明锚点，不贡献识别置信度或信息权限。
7. 当前感知分辨率和身份识别置信度均由确定性规则求值。
8. 感知识别只返回最小档案引用、称呼和置信度，完整背景必须按需检索。
9. 相关性和可达性分别计算，再通过线索激活决定是否进入候选。
10. 混合检索组合结构索引、关联图、必需但可替换的语义相似度和当前情境。
11. 记忆 Agent 只能重排已经通过门槛的有限候选。
12. 检索结果必须经过 Working Memory 容量准入，命中不等于想起。
13. 只有认知确认消费的结果才会得到强化。
14. 已删除内容和审计归档永远不能成为运行时记忆来源。
15. 记忆处理在固定稳定边界顺序执行，失败时整体阻塞且不产生部分提交。
16. 前瞻性意图属于认知系统；记忆系统只复用召回与 Working Memory 能力，不参与意图竞争或选择。
17. 记忆片段的临时主观解释在同一次认知调用中完成，不建立独立回忆重建 Agent 或持久对象。
18. Identity 和背景文本不会被记忆实例创建流程自动转换为长期记忆。
