# 时间与整体调度系统设计

## 1. 文档目的

本文定义时间与整体调度系统的产品级模型、职责边界和运行语义。该系统维护唯一模拟时钟，以固定 Tick 组织世界、身体、降级行为树、感知、认知和记忆处理，并负责普通连续运行、零 LLM 的 Fast Forward、跨系统屏障、暂停和显式保存。

本文保持世界观和技术实现无关，不规定编程语言、线程模型、存储产品、通信协议或具体 Tick 时长。

## 2. 设计目标

时间与整体调度需要满足：

* 一个世界实例只有一条权威模拟时间线和一个当前 Tick 身份。
* 手动推进与连续运行使用完全相同的固定 Tick 语义。
* 世界、身体和确定性过程可以在没有认知调用时持续更新。
* 睡眠、昏迷和麻醉由身体状态逐 Tick 演化，不被简化为调度器定时唤醒。
* 当所有主要实体无法接入认知时，可以用零 LLM 的 Fast Forward 快速推进相同 Tick。
* 主要地位是正常实体上的独立调度属性，不由控制来源或认知内容自动推出；非主要正常实体不能阻止或打断普通快进。
* 降级实体使用确定性行为树产生简单身体计划，不建立认知和主观记忆实例。
* 规则解析、认知决定和必要记忆处理都在明确屏障内完成，不让现实等待消耗模拟时间。
* 固定 Tick 能为后续动作可视化提供统一时间轴，同时不要求每 Tick 全量扫描所有对象。

## 3. 职责边界

### 3.1 时间与整体调度系统负责

* 维护当前模拟时间、Tick 身份、固定 Tick 时长和当前运行模式。
* 接受单步、连续、Fast Forward、暂停、恢复、保存退出和终止控制。
* 按固定阶段调用各权威子系统，并确认阶段完成状态。
* 维护主要认知参与者集合及其当前认知参与许可视图。
* 判断何时进入或退出 Fast Forward，并保证快进期间不发生任何 LLM 调用。
* 管理活动实例、目标 Tick 定时项和阶段日志。
* 建立和解除规则解析屏障与全局认知屏障。
* 形成面向控制、状态展示和授权诊断的运行结果。

### 3.2 时间与整体调度系统不负责

* 不决定世界事实、身体指标、动作结果或感知内容。
* 不形成角色意图、认知决定、主观记忆或 Identity 变化。
* 不解释睡眠、昏迷、疲劳、药物或刺激的领域含义。
* 不通过主要标记赋予角色世界内身份、行动优先级或信息权限。
* 不替非主要正常实体补写快进期间的经历。
* 不定义第三方行为树节点语言、创作工具或具体动物行为，只定义组件适配契约。
* 不在 Fast Forward 中使用 LLM 补充规则、认知、记忆或离屏故事。
* 不以事件跳时、近似更新或跳过 Tick 代替确定性模拟。
* 不拥有其他子系统的权威状态，也不保存其第二份可写副本。

## 4. 时间与运行状态模型

### 4.1 模拟时钟

每个世界实例只有一个模拟时钟。时钟包含当前模拟时间、当前 Tick 身份、固定 Tick 时长以及时间线身份。世界、身体、角色和动态实体不能分别推进自己的时钟。

机器时间、渲染时间、模型调用耗时、用户等待时间、暂停时间和离线时间均不是模拟时间输入。

### 4.2 固定 Tick

一次 Tick 将模拟时间推进一个配置化固定步长，并执行一套完整、稳定的跨系统阶段。Tick 时长属于运行配置；运行期间不能静默改变。需要更改时必须通过显式配置更新，并由时间和各领域验证当前过程是否兼容。

手动模式的一次操作只执行一个完整 Tick。连续模式只是自动重复相同 Tick，不产生另一套状态更新语义。

### 4.3 运行模式

时间系统至少区分：

* **单步就绪：** 等待用户请求下一个 Tick。
* **普通连续：** 按产品设定的现实配速自动执行 Tick。
* **Fast Forward：** 取消普通现实配速并降低非必要展示频率，高速重复完整 Tick，且系统级禁止 LLM。
* **屏障等待：** 当前 Tick 因规则、认知、用户输入或必要处理而冻结。
* **暂停：** 不开始新 Tick，仅允许查询、保存和授权管理操作。
* **静止：** 没有可推进活动或没有可达主要认知边界，停止空转并等待外部输入。
* **失败：** 当前阶段不能完成，停止自动推进并返回诊断。

运行模式只改变是否自动继续、现实配速和展示频率，不能改变同一 Tick 的确定性领域规则。

### 4.4 活动集合与目标 Tick 索引

固定 Tick 不要求扫描所有实体和规则。各领域登记当前活动实例、脏状态和需要在目标 Tick 重新检查的项目，调度器只唤醒相关入口。

目标 Tick 索引用于高效找到本 Tick 需要处理的冷却、等待、有限期限或低频维护项。它不允许跳过中间 Tick，也不替领域推导睡眠结束、动作完成或认知内容。登记遗漏属于可诊断的一致性错误，不能静默让过程永久停滞。

### 4.5 可视化时间轴

动作阶段、身体过程、行为树状态和世界变化都关联明确 Tick。后续可视化可以读取相邻稳定 Tick 快照、当前阶段和已提交进度进行展示或插值。

渲染帧率可以高于或低于模拟 Tick；插值只影响展示，不能提交世界、身体或动作状态。Fast Forward 可以降低采样与渲染频率，但不能省略权威 Tick。

## 5. 实体调度分类

### 5.1 递进能力模型

普通动态实体、降级实体和正常实体不是三个互不相关的并列类别，而是共享同一运行基础的递进能力层级：

**普通动态实体 → 增加行为树决策模块成为降级实体 → 以完整感知、认知和记忆模块替换行为树决策模块成为正常实体**

后一级继承前一级的世界存在、固定 Tick 更新、活动索引、保存恢复及适用的身体执行能力。“替换”表示一个运行实例只能选择一种自主决策模块：降级实体使用行为树，正常实体使用完整主观链路，不能同时运行两套决策器。

| 能力 | 普通动态实体 | 降级实体 | 正常实体 |
| --- | --- | --- | --- |
| 世界存在、固定 Tick、活动索引、保存恢复 | 有 | 继承 | 继承 |
| 身体状态与动作执行 | 按内容需要 | 形成身体计划时必需 | 必需 |
| 自主决策模块 | 无 | 确定性行为树与有限黑板 | 完整感知、认知、记忆与意图 |
| 主观经历与记忆 | 无 | 无 | 有 |
| 主要实体资格 | 无 | 无 | 可由产品配置授予 |

控制来源和主要地位是叠加在该能力层级上的受保护属性。主要地位仍不会由完整认知能力自动推出。

### 5.2 普通动态实体

普通动态实体提供最小运行基础：世界实体状态、确定性过程、固定 Tick 更新、活动索引、事件来源及保存恢复。它不具备自主决策模块，只依据世界过程、身体过程或其他确定性规则更新。

普通动态实体可以按内容需要拥有简单身体状态或完全由世界过程描述，但不能形成自主身体计划。其是否处于活动状态不参与主要认知判断。

### 5.3 降级实体

降级实体是普通动态实体的能力超集。它保留普通动态实体的全部运行基础，并增加可执行动作所需的身体关联、确定性行为树、受限局部执行视图和有限黑板，从而能够形成简单身体计划。

降级实体不创建完整感知、认知系统、认知 LLM、Working Memory、Recent Memory、Long-term Memory、主观实体档案或前瞻性意图。行为树黑板只是决策器运行状态，不能扩展成隐藏主观记忆。

降级实体必须是非主要实体。配置将降级实体标记为主要时必须拒绝加载，而不是在运行时自动修正。

### 5.4 正常实体

正常实体是降级实体在产品能力上的进一步超集：它保留共同的世界、身体、Tick、动作、生命周期和保存恢复能力，但用完整感知、认知、Working Memory、持久记忆和意图模块替换行为树与有限黑板决策模块。

正常实体不能同时运行自主行为树和完整认知决策。需要复用的确定性动作习惯应通过身体规则、已接纳动作或未来明确设计的认知能力表达，不能把降级行为树作为认知失败时的隐藏后备决策器。

AI 控制的正常实体通过认知 LLM 形成决定；用户控制的正常实体保留完整感知、认知连续状态和主观记忆模块，但由用户决定入口替代自主认知 LLM。控制来源不同不改变其正常实体能力层级。

### 5.5 主要实体

主要实体参与 Fast Forward 的进入和退出判断。用户控制的正常实体默认是主要实体；配置可以指定重要 AI 正常实体为主要实体。主要实体必须拥有合法的用户决定入口或完整认知入口，因此普通动态实体和降级实体不能成为主要实体。

主要地位只表示产品希望等待其意识判断和恢复交互的调度焦点，不代表角色在世界内更重要、更容易成功或拥有额外知识。

### 5.6 非主要正常实体

非主要正常实体在普通模式下可以拥有完整感知、认知和记忆链路，也可以产生正常认知屏障。它们不参与 Fast Forward 进入条件；进入快进后，其所有新认知处理和 LLM 调用被完整跳过。

非主要正常实体在快进中的既有动作和身体过程仍然推进。动作完成后如果需要新决定，实体保持没有新计划的状态，不因此退出快进。

### 5.7 信息隔离

主要标记、普通动态、降级或正常能力层级、控制来源和快进策略都是受保护的系统信息，不属于世界 Ground Truth，也不能通过普通感知、对话、记忆或行为树局部视图泄漏。

## 6. 睡眠、昏迷与认知恢复

### 6.1 身体状态而非调度定时器

睡眠、昏迷、麻醉及其他认知不可接入状态由身体模式、身体指标、持续过程和效果映射形成。调度器不内置“睡满八小时”“固定若干 Tick 后醒来”或任何按名称触发的自动恢复。

配置可以定义身体过程阶段、恢复速率、最低阶段、最早可能恢复条件或刺激效果，但这些都由身体系统在每个相关 Tick 求值。

### 6.2 不停止世界与身体 Tick

认知不可接入不会冻结该实体身体，也不会冻结世界。恢复、恶化、环境变化、已有动作、被其他实体移动或触碰以及外部影响继续通过正常 Tick 发生。

身体系统在每个相关 Tick 依据当前身体状态和已裁定输入重新计算认知参与许可。许可变化必须与对应身体版本和来源关联。

### 6.3 外部刺激

声音、触碰、疼痛、光线、伤害、药物变化或其他刺激必须先成为世界或身体系统接受的影响，再通过配置规则改变身体模式、感官条件或认知参与许可。调度器不能仅凭一个“刺激”标签直接唤醒角色。

### 6.4 恢复交接

认知参与许可从禁止转为允许时，身体系统形成受保护恢复边界；感知系统使用恢复时仍有效的世界、身体和刺激材料生成一次性恢复上下文。

恢复上下文只包含当前实际可获得的环境、身体感觉、持续刺激、残留痕迹及主观可察觉的连续或断裂。它不能包含空档期间完整事件历史、隐藏原因或已经消失的刺激。

调度器只有在恢复上下文就绪且当前参与资格有效时，才登记主要实体的恢复认知需求。许可恢复本身不替角色形成理解、记忆或动作。

## 7. Fast Forward

### 7.1 进入条件

当所有处于运行状态的主要实体都禁止认知参与时，调度器在当前稳定 Tick 边界进入 Fast Forward。非主要实体是否清醒、是否拥有完整认知系统以及是否正在活动都不阻止进入。

如果当前没有任何主要实体，配置必须明确该世界是否允许仅以降级和动态实体运行；不能依靠空集合判断无条件进入永久快进。

### 7.2 零 LLM 不变量

Fast Forward 是系统级零 LLM 模式。期间禁止启动：

* AI 角色认知调用。
* 用户自然语言输入解释调用。
* 非主要正常实体的认知调用。
* 记忆 Agent、语义重排或其他依赖 LLM 的记忆处理。
* 缺失规则的 LLM 生成。
* 离屏叙事、经历补写或任何隐藏模型调用。

进入快进前必须停止当前模型调用；Fast Forward 中不启动新的模型请求。

### 7.3 继续运行的处理

Fast Forward 中继续执行世界、身体、确定性感知检查、行为树、索引维护、确定性规则、意图和 Working Memory 的时间衰减，以及不需要模型的其他维护。

快进不能跳过 Tick、改变规则、提高实体优先级或近似身体恢复。相同初始快照和相同数量 Tick 下，Fast Forward 与逐次手动 Tick 的确定性世界、身体和行为树结果必须一致。

### 7.4 现实执行节奏

Fast Forward 取消普通连续模式的现实配速，允许批量执行多个完整 Tick，并降低中间 UI 刷新、渲染和普通日志展示频率。每个批次必须定期让出执行权，以处理暂停、保存、退出、运行上限和状态查询。

批量执行只优化外层循环，不能合并领域更新或跳过单个 Tick 的阶段日志。

### 7.5 退出条件

以下情况结束 Fast Forward：

* 任一主要实体恢复认知参与资格并形成恢复或其他认知需求。
* 主要实体在可认知状态下出现必须处理的决策边界。
* 世界变化缺少规则，需要建立规则解析屏障。
* 到达用户指定的 Tick、模拟时间或快进上限。
* 收到暂停、保存退出或终止请求。
* 出现阶段失败、配置错误、不可收敛连锁或不可恢复错误。

缺少规则时必须先退出 Fast Forward，再由普通屏障流程决定是否调用规则生成 LLM。系统不能在快进标记仍然有效时偷偷发起模型请求。

### 7.6 不构成退出的情况

以下情况本身不结束 Fast Forward：

* 非主要正常实体产生普通认知需求。
* 非主要实体动作完成、失败、中断或进入空闲。
* 降级实体行为树选择新动作或节点转换。
* 普通动物或环境实体保持清醒。

这些实体产生的客观影响仍正常传播。如果影响改变主要实体身体许可、建立规则屏障或造成系统失败，则由相应结果结束快进。

### 7.7 无可达主要认知边界

当全部主要实体持续禁止认知参与，并且不存在能够改变其许可的活动身体过程、世界过程、外部输入或有效未来检查时，系统进入“无可达主要认知边界”的静止状态。

静止不是角色死亡或永久昏迷的世界事实，只表示调度器当前没有可验证的继续推进价值。外部世界输入、管理操作或配置变化可以重新激活运行。

## 8. 非主要正常实体的快进语义

### 8.1 认知完全跳过

Fast Forward 期间不为非主要正常实体建立认知屏障，不调用认知 LLM，不执行用户输入解释，也不建立等待事后回放的认知轮次。

已有认知状态和 Long-term Memory 不因快进被伪造修改；已经开始的身体动作继续由身体系统推进。需要新决定时只保持无新计划状态。

### 8.2 观察与主观经历

快进期间不为非主要正常实体编码新的主观经历、反思、关系认识或主观实体断言。普通观察可以为确定性连续检查短暂形成，但不能无限排队等待事后处理。

未被认知消费的离屏观察按配置确定性折叠、失效或删除。退出快进后只从当时实际可感知的当前状态继续，不回放、总结或补算快进期间经历。

### 8.3 时间衰减

Working Memory、意图可达性以及其他明确以模拟时间为输入的确定性衰减继续运行。衰减不能生成新的主观内容，也不能把快进解释为角色主动遗忘。

Long-term Memory 保留。需要 LLM 的巩固、重排、解释或其他记忆任务进入受保护延后队列。

### 8.4 延后模型任务

进入延后队列的记忆候选必须保留原来源、触发 Tick、配置版本、语义版本和幂等身份。它们在 Fast Forward 中不得仅因模型处理被禁止而错误到期删除。

退出后，延后任务先依据当前状态和版本重新验证，再处理、迁移或明确失效。延后任务不能反向创造快进期间的认知经历，也不能在恢复前阻止主要实体的客观身体恢复。

### 8.5 离屏空档边界

调度器为受影响角色保存受保护的离屏空档开始和结束边界，用于清理过时输入、核对衰减、拒绝迟到响应和重新验证认知状态。

离屏空档不是角色知识，不能作为感知、记忆或提示内容告诉角色“意识被系统跳过”。它也不同于睡眠或昏迷的身体认知中断，不自动生成恢复上下文。

## 9. 降级实体与行为树

### 9.1 运行职责

降级实体通过配置化确定性行为树形成简单行动选择。行为树可以表达条件、选择、顺序、重复、等待、冷却、当前动作检查及有限黑板操作。

完整节点规范、内容创作工具和复杂行为库由满足适配契约的第三方组件提供，不作为 AgentLife 的独立详细设计子系统。本系统只规定其调度、权限、输出和恢复边界。

### 9.2 输入权限

行为树只能读取：

* 配置允许的局部世界执行视图。
* 自身身体状态、能力、资源和动作结果的用途受限视图。
* 明确写入有限黑板的确定性状态。

局部执行视图不是完整角色感知，不形成主观经历。行为树不能读取完整 Ground Truth、远处隐藏事实、其他角色私有认知或记忆、控制来源、主要标记、审计归档和调试信息。

### 9.3 输出边界

行为树输出与正常实体认知相同产品语义的短身体计划。计划仍需经过身体能力、资源冲突、动作并发、当前前提和世界规则验证。

行为树不能直接修改身体或世界，不能创建规则，不能调用 LLM，也不能因 Fast Forward 获得行动优先级。缺少规则或动作无法表达时，节点返回明确失败并由树的已配置分支处理；没有分支时保持可诊断失败。

### 9.4 Tick 与动作连续性

行为树在普通模式和 Fast Forward 使用相同 Tick 语义。它只在配置规定的检查条件满足、当前动作到达决策点或相关黑板输入改变时求值，不要求每 Tick 从根节点全量重跑。

本 Tick 形成并接纳的新身体计划从下一 Tick 开始积累进度，避免因实体遍历顺序获得额外模拟时间。

### 9.5 保存与恢复

必须保存当前节点状态、有限黑板、等待及冷却、最近输入版本、活动身体计划关联和幂等身份。恢复不能重复选择、重复提交计划或让同一冷却提前结束。

## 10. Tick 阶段顺序

一个完整 Tick 使用以下产品级顺序：

1. 固定 Tick 身份、运行模式、配置版本、起始状态版本和本 Tick 活动入口。
2. 将模拟时钟推进一个固定步长，并唤醒相关世界、身体、行为树及确定性维护实例。
3. 推进已有身体动作、身体过程、睡眠或昏迷模式、世界动态实体和世界过程，形成候选影响。
4. 执行需要决策的降级实体行为树；Fast Forward 中不执行任何正常实体的新认知决定。
5. 世界系统裁定候选影响，身体系统吸收已提交结果并重新计算指标、模式、感官效率和认知参与许可。
6. 传播同一 Tick 内由已提交变化触发的确定性结果，使用稳定顺序、来源去重和收敛限制达到客观稳定状态。
7. 若发现缺失规则，冻结当前 Tick 并建立规则解析屏障；完成原子规则更新和原请求重新验证前不进入后续阶段。
8. 执行必要的确定性感知、身份关联、恢复条件检查和主要实体恢复上下文生成。
9. 汇总认知需求。普通模式可以处理主要与非主要正常实体；Fast Forward 只检查主要实体的退出条件，并丢弃非主要实体本轮认知需求。
10. 必要时建立全局认知屏障，完成 Working Memory 准入、意图召回、记忆查询、AI 决定、用户输入或跳过及身体计划交接。
11. 执行当前模式允许的记忆编码、档案更新、巩固、强化、衰减、到期删除和归档；Fast Forward 延后所有依赖 LLM 的任务。
12. 写入阶段完成记录，发布稳定 Tick 快照，并决定进入单步就绪、普通连续、Fast Forward、暂停、静止或失败。

同一 Tick 内的确定性传播不能无限循环。达到配置化传播上限仍未稳定时进入失败状态，不能带着半稳定结果进入下一 Tick。

## 11. 屏障语义

### 11.1 规则解析屏障

确定性阶段遇到缺失规则时，保留此前已经合法提交的独立结果，冻结当前 Tick 并登记原请求、依赖版本和未完成阶段。

规则解析屏障优先于认知屏障。只有规则生成、验证、原子配置更新以及原请求重新验证完成后，感知和认知才能读取本 Tick 的最终客观状态。

Fast Forward 中发现缺失规则时先退出快进；退出完成前不得调用规则生成 LLM。

### 11.2 全局认知屏障

普通模式下，稳定客观状态产生必须解决的认知需求时，调度器固定当前 Tick、配置版本、参与者集合和各角色用途受限输入。

必要 AI 调用可以在现实计算层并发，但读取同一模拟快照。用户等待和模型返回顺序不产生模拟优先级。所有必要参与者完成、跳过或被明确处置，身体计划完成统一接纳，并且本边界必要记忆处理完成后，屏障才能解除。

### 11.3 Fast Forward 与认知屏障

Fast Forward 中不为非主要正常实体建立屏障。主要实体恢复参与资格并需要决定时，调度器先结束 Fast Forward，再在普通模式建立认知屏障。

模式切换和屏障建立必须处于同一安全边界，不能让一个模型请求在仍标记为 Fast Forward 的 Tick 中启动。

### 11.4 屏障中的模拟时间

任何屏障期间模拟时间、动作进度、身体消耗、恢复过程、世界过程和行为树冷却都保持不变。现实等待不参与任何领域规则求值。

## 12. 运行控制

### 12.1 单步

单步请求从稳定边界开始，执行一个完整 Tick，并在新的稳定边界返回。若 Tick 中建立屏障或失败，单步保持未完成状态，不越过屏障启动下一 Tick。

### 12.2 普通连续

普通连续模式自动重复 Tick，并可以使用产品设定的现实配速。它在认知屏障、规则屏障、暂停、目标到达、静止或失败时停止自动推进。

### 12.3 Fast Forward 批次

Fast Forward 可以连续执行多个 Tick，但每个批次必须受配置化最大 Tick 数或现实执行预算限制。批次结束时检查控制请求、主要实体许可、屏障、错误和停止条件，再决定是否继续。

### 12.4 暂停

暂停请求在最近的安全阶段边界生效。已开始的单个领域原子提交不得被截断；完成后调度器不进入下一阶段或下一 Tick。

暂停期间允许只读查询、保存和授权管理操作。普通角色动作请求、世界变化请求和行为树推进等待恢复后进入正常阶段。

### 12.5 停止条件

连续运行和 Fast Forward 可以登记目标 Tick、目标模拟时间、最大推进 Tick 数或明确管理停止条件。停止条件只终止自动推进，不自动取消活动动作、身体过程、意图或决定。

## 13. 显式保存与加载

PoC 只在完整稳定 Tick 边界保存。存档记录当前模拟时间、Tick、运行模式、配置版本、活动实例及各 Service 的权威状态。

加载时恢复到该稳定 Tick，并从下一 Tick 继续。Tick 中间保存、失败阶段续做、时间线分支、迟到响应隔离和异常进程恢复不在 PoC 范围内。

## 14. 配置与验证

运行配置至少需要表达：

* 固定 Tick 时长和普通连续模式配速策略。
* Fast Forward 批次预算、展示采样和安全让出策略。
* 主要实体标记和实体能力层级。
* 普通动态基础、降级行为树扩展和正常主观链路替换所需的组件组合。
* 行为树引用、局部世界视图白名单、身体视图和黑板限制。
* 活动检查、目标 Tick、确定性传播上限和停止条件策略。
* 离屏观察折叠和衰减策略。

配置必须拒绝：

* 把降级实体标为主要实体。
* 为降级实体配置认知、主观记忆或 LLM 入口。
* 为普通动态实体配置自主决策入口，或为正常实体同时配置行为树和完整认知决策器。
* 允许行为树读取完整世界、私有认知、主观记忆或调试视图。
* 在 Fast Forward 中启用任何 LLM 或生成式回填。
* 使用调度器定时器按名称强制结束睡眠或昏迷。
* 允许运行期间静默改变 Tick 时长。
* 无法判定收敛的零时间循环。

## 15. 跨系统协作

### 15.1 与世界系统

世界系统维护客观事实、世界过程和事件。调度器提供 Tick 身份、显式模拟时间和阶段入口，不替世界裁定结果。

世界缺少规则时建立规则屏障；Fast Forward 必须先退出，才能进入可能调用 LLM 的规则生成流程。

### 15.2 与人物系统

人物系统维护角色控制来源、实体能力层级、主要标记和子系统关联。调度器只读取受保护运行视图，不能把这些信息变成角色可见属性。

人物系统验证降级实体没有认知和主观记忆实例，且不能被配置为主要实体。

### 15.3 与身体系统

身体系统逐 Tick 推进动作、过程、睡眠或昏迷模式，并提供版本化认知参与许可。调度器不推导身体状态含义。

正常实体认知和降级行为树产生的计划都通过同一身体执行入口验证。正常实体不得同时保留行为树自主来源；新接纳计划从下一 Tick 开始积累进度。

### 15.4 与感知系统

感知系统在客观状态稳定后形成有限观察和恢复上下文。Fast Forward 中只执行恢复检查、主要实体退出判断及其他明确需要的确定性感知处理。

非主要正常实体的离屏观察不能无限积累，也不能在退出后回放为主观经历。

### 15.5 与认知系统

普通模式下认知调度可以为主要和非主要正常实体建立屏障。Fast Forward 中所有正常实体认知调用都禁止，非主要认知需求直接按离屏策略丢弃，主要恢复需求用于结束快进。

主要标记不改变角色在普通认知屏障中的输入权限、模型能力或行动规则。

### 15.6 与记忆系统

普通模式下记忆系统按稳定边界执行准入、召回、编码、巩固和衰减。Fast Forward 中跳过依赖 LLM 的记忆处理。

非主要正常实体不会因离屏观察形成 Recent 或 Long-term Memory；退出后也不执行事后经历补写。

### 15.7 与统一配置与规则基础设施

共享基础设施验证 Tick、主要标记、实体能力层级、决策模块互斥、行为树引用、局部视图权限、Fast Forward 策略和阶段规则，并为活动索引和确定性求值提供能力。

共享基础设施不能推进时钟、切换模式、解除屏障、运行行为树、调用 LLM 或提交领域权威状态。

## 16. 产品级概念接口

### 16.1 时钟与状态查询

返回当前模拟时间、Tick、固定 Tick 时长、运行模式、阶段、屏障和停止原因。普通产品视图不得包含受保护实体分类或隐藏诊断。

### 16.2 单步 Tick

从稳定边界执行一个 Tick，返回完成、屏障、暂停、静止或失败结果。

### 16.3 连续运行

开始普通连续 Tick，接受目标 Tick、目标模拟时间或最大步数，并在停止条件出现时返回。

### 16.4 Fast Forward 控制

查询进入条件、开始或继续快进批次，并在主要实体恢复、屏障、控制请求、上限或错误时结束。接口必须保证调用期间零 LLM。

### 16.5 主要实体管理

通过授权配置或管理操作登记、移除和查询主要实体。变更必须经过实体能力层级验证，并从下一个安全边界生效。

### 16.6 活动与目标 Tick 登记

领域系统登记、取消或重新安排活动实例和目标 Tick 检查。接口不接受自由文本时间推断，也不替领域生成完成结果。

### 16.7 行为树调度

在合法阶段向降级实体提供受限局部世界视图、身体视图和黑板，执行确定性树并接收短身体计划或明确失败。

### 16.8 屏障协调

建立、查询和解除规则或认知屏障。接口验证当前模式、参与者完成状态、必要记忆处理和身体计划交接。

### 16.9 暂停与恢复

请求在最近安全阶段暂停，并恢复普通运行。现实暂停时间不计入模拟时间。

### 16.10 整体保存与加载

在稳定 Tick 边界保存各 Service 状态和配置版本，并从该边界加载。

### 16.11 授权诊断

提供 Tick 阶段、活动集合、快进进入与退出原因、离屏空档、延后任务、传播次数和失败来源。诊断与角色运行时信息通道严格隔离。

## 17. 结果与失败语义

时间与整体调度至少区分：

* **Tick 完成：** 当前 Tick 的全部必要阶段已经稳定提交。
* **普通连续中：** 可以按普通现实配速自动执行下一 Tick。
* **Fast Forward 中：** 当前满足零 LLM 快进条件。
* **等待规则：** 当前 Tick 有未解决规则请求，模拟时间冻结。
* **等待 AI：** 普通认知屏障仍有 AI 参与者未完成。
* **等待用户：** 普通认知屏障仍有用户参与者未输入或跳过。
* **已暂停：** 已在安全阶段停止推进。
* **已达目标：** 到达请求的 Tick、模拟时间或最大步数。
* **静止：** 当前没有可推进活动或没有可达主要认知边界。
* **阶段失败：** 当前 Tick 停止并返回诊断。

失败不能被解释为角色睡眠、遗忘、无意图或选择不行动。

## 18. 验收场景

1. 手动执行一个 Tick 与连续模式执行同一 Tick 得到相同确定性结果。
2. Fast Forward 与相同数量的手动 Tick 得到相同世界、身体和行为树结果。
3. 动作、身体过程和未来可视化能够共享同一 Tick 时间轴。
4. 固定 Tick 不导致每轮扫描全部实体和规则。
5. 角色不会因为经过固定八小时自动醒来。
6. 睡眠、昏迷或麻醉期间，世界、身体恢复和外部影响继续推进。
7. 声音、触碰或疼痛只有经过世界与身体规则后才可能改变认知参与许可。
8. 恢复认知只获得当前仍可感知的材料，不获得空档完整历史或隐藏原因。
9. 用户和主要 AI 全部无法接入认知时，即使非主要正常实体清醒，系统仍进入 Fast Forward。
10. Fast Forward 期间不存在 AI 认知、用户输入解释、记忆 Agent、语义重排、规则生成或其他 LLM 请求。
11. 非主要正常实体已有动作继续完成，随后需要新决定时保持空闲且不阻塞快进。
12. 非主要正常实体在快进中不形成新主观记忆，退出后不回放或补算经历。
13. 离屏观察能够确定性折叠或删除，不会无限积累。
14. 需要 LLM 的记忆任务在快进中受到保护并延后，退出后先重新验证。
15. 降级兔子可以在主要角色睡眠时继续通过行为树活动，但其清醒不阻止快进。
16. 降级实体动作产生的声音或触碰可以按正常规则影响主要角色的身体唤醒条件。
17. 行为树无法读取远处隐藏事实、完整世界状态、私有认知或主观记忆。
18. 行为树计划与正常实体认知计划接受相同身体和世界验证。
19. 本 Tick 新接纳的计划从下一 Tick 开始积累进度，不受遍历顺序影响。
20. 快进遇到缺失规则时先退出并建立屏障，不在快进中调用 LLM。
21. 主要实体恢复资格时，Fast Forward 在对应 Tick 边界结束，并只产生一次恢复交接。
22. 永久不可接入且不存在任何可能改变状态的过程时，系统进入静止而不是无限空转。
23. 同 Tick 确定性传播不收敛时进入可见失败，不开始下一 Tick。
24. 普通动态实体可以运行世界及身体确定性过程，但没有自主计划来源。
25. 降级实体复用普通动态实体的身份、Tick 和活动索引，并额外通过行为树形成身体计划。
26. 正常实体继续复用共同世界、身体和生命周期能力，但以完整感知、认知和记忆链路替换行为树决策模块。
27. 配置不能让同一实体同时加载行为树与完整认知决策，也不能把普通动态实体或降级实体标记为主要实体。

## 19. 范围边界

本文不定义：

* 具体 Tick 时长、现实配速、批次大小或渲染帧率。
* 具体世界的睡眠阶段、疲劳、伤病、药物和唤醒数值。
* 第三方行为树节点规范、编辑器、调试器、行为内容或平衡参数；本系统只保留适配契约。
* 快进期间的离屏故事生成、事后经历补写或代理认知。
* 时间线分支、联网同步或多人实时控制。
* 完全确定性的 LLM 重放。
* 跨系统全局回滚事务或具体持久化实现。

## 20. 设计约束总结

1. 模拟只使用一条权威时间线和固定 Tick。
2. 单步、连续和 Fast Forward 使用相同领域更新语义。
3. Fast Forward 是高速完整 Tick，不是事件跳时或近似模拟。
4. Fast Forward 期间系统级禁止所有 LLM 调用。
5. 普通动态、降级和正常实体形成递进能力层级；正常实体以完整主观链路替换行为树决策模块。
6. 主要地位是正常实体上的独立调度属性，不由控制来源、认知内容或世界身份推出，也不属于世界事实。
7. 非主要正常实体在快进中完全跳过认知且不补算经历。
8. 降级实体只能使用确定性行为树和有限黑板，并且必须非主要。
9. 行为树只读取受限局部视图，输出仍需经过身体和世界验证。
10. 睡眠、昏迷和恢复由身体状态逐 Tick 决定，不由调度器定时唤醒。
11. 认知许可恢复后仍需感知过滤和明确认知需求。
12. 规则屏障先于认知屏障，任何屏障期间模拟时间不推进。
13. 本 Tick 新计划从下一 Tick 开始积累进度。
14. 显式存档只在稳定 Tick 边界创建和加载。
15. 固定 Tick 支持统一可视化时间轴，但不要求全量扫描或逐 Tick 渲染。
