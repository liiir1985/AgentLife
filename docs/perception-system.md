# 感知系统设计

## 1. 文档目的

本文定义感知系统的产品级模型、职责边界和运行语义。感知系统把世界与身体提供的客观材料转换为某个角色在当时条件下实际获得的有限观察，并把这些观察交给认知、认知调度和后续记忆流程使用。

感知系统不模拟真实生物传感器，也不要求使用自然语言描述脸部、声纹或步态进行身份匹配。系统以结构化观察、可辨认条件和角色自己的主观身份关联表达日常感知。本文不固定具体世界采用哪些感官、阈值、数值、编程语言、存储方案、类结构或接口字段。

## 2. 设计目标

感知系统需要保证：

* 角色只能获得其位置、身体感官、环境条件和注意状态允许获得的信息。
* 世界 Ground Truth、感知观察、认知理解和记忆内容保持分离。
* 感知结果能够表达细节缺失、模糊和不确定，而不是把客观事实完整复制给角色。
* 日常对象能够被组织成认知可直接使用的有限观察，无需认知从仿传感器原始信号重新识别物体。
* 身份识别只使用角色已经形成的主观身份关联，不能借助实体标识读取对方完整人物设定。
* 当前没有调用 LLM 不等于感知停止；明确的认知中断也不会被事后补写为完整经历。
* 当前注意可以限制普通材料，高显著刺激仍可形成突破注意的观察和认知唤醒建议。
* 稳定场景不会在每个 Tick 重复产生相同观察，连续变化可以保持对象连续性。
* 感知处理不调用 LLM，不在 Tick 内等待外部生成，也不直接修改世界、身体、认知或记忆。
* 未消费观察、连续追踪和恢复交接可以保存与恢复，且不会重复交付。

## 3. 职责边界

### 3.1 感知系统负责

感知系统负责：

* 建立并维护 AI 角色的感知实例。
* 加载和验证感官通道、材料类型、筛选条件、注意与显著度策略、分辨率规则和渲染规则。
* 接收世界提供的环境、实体、关系变化和客观事件材料。
* 接收身体提供的感官可用性、效率修正、身体感觉材料和受限转换来源。
* 依据空间、遮挡、环境、感官和注意条件筛选候选刺激。
* 把可获得的刺激组织为有限的结构化观察。
* 判断当前观察是否足以进行身份关联查询，并使用最小查询结果形成识别表现。
* 维护短期观察连续性、变化检测、聚合和重复抑制。
* 维护尚未被认知消费的感知流及其交付状态。
* 为认知调度形成建议唤醒信号，但不直接启动认知或 LLM。
* 在明确的认知中断恢复时生成受限恢复上下文。
* 提供结构化观察到认知可读文本的稳定渲染。
* 保存和恢复继续运行所需的感知状态。

### 3.2 感知系统不负责

感知系统不负责：

* 维护世界事实、人物真实身份、身体指标或客观事件历史。
* 读取或复制其他角色的完整 Identity、认知、记忆和隐藏状态。
* 判断观察对象的真实意图、行为原因、道德含义或事件意义。
* 决定角色相信什么、如何解释矛盾信息或采取什么行动。
* 接受他人的身份声明、创建主观实体档案或修改记忆。
* 通过自由文本描述进行脸部、声纹、步态或其他生物特征匹配。
* 因世界知道某个实体是谁，就自动让观察者知道该身份。
* 把未感知的客观事件、调试信息或控制来源补写为角色经历。
* 决定认知何时实际运行，或直接把唤醒建议变成 LLM 调用。
* 把观察自动编码为近期记忆或长期记忆。

## 4. 感知信息分层

### 4.1 感知配置

感知配置描述某类感知实例能够使用的感官通道、接受的材料类型、实体感知投影、可达性与筛选规则、注意和显著度策略、细节分辨率、观察聚合、重复抑制及文本渲染方式。

配置描述通用机制，不包含角色运行中已经观察到的内容，也不直接表达某个角色认识谁。当前感官效率来自身体运行状态，当前注意来自认知状态，主观身份关联来自记忆系统；这些内容不能写回配置作为运行状态。

### 4.2 客观感知材料

客观感知材料是世界或身体针对某个观察时点提供、可供进一步筛选的结构化输入。材料可以描述当前环境表现、实体外在表现、已经提交的事件表现、身体感觉或仍在持续的刺激。

材料可以带有来源实体、世界事件、身体变化和状态版本的受保护关联，以支持可达性判断、连续追踪、去重和审计。这些关联不等于角色已经知道的信息，不能原样进入普通认知上下文。

客观材料只是潜在输入。世界事件发生或身体发生变化，不表示角色一定感知到了它。

### 4.3 实体感知投影定义

实体感知投影定义是设计时配置，用于声明某类实体事实如何变成可以交给感知系统继续处理的外在描述。它不是实体当前状态，也不是已经形成的观察。

每项投影定义至少声明：

* 允许读取的世界感知材料类型或已授权外在事实。
* 适用的实体类型、感官通道和环境前提。
* 输出的感知描述词汇，例如类别、外观、姿态、动作、相对位置或可见携带物。
* 每项描述所需的最低细节分辨率，以及较低分辨率下允许使用的粗化结果。
* 无法确认时的省略或不确定表达，不允许使用完整事实兜底。
* 多项描述的组合方式、稳定顺序、冲突处理和变化检测语义。

投影采用显式白名单。没有投影定义的世界字段不能通过通用序列化、反射、调试视图或自然语言拼接进入观察。实体实例可以引用类型投影并提供经过验证的外在表现覆盖，但不能借覆盖暴露人物真实身份、认知、记忆、控制来源或其他隐藏状态。

### 4.4 候选刺激

候选刺激是经过材料类型、观察范围和基础通道检查后，可能影响当前观察者的材料。候选刺激保留尚待判断的空间、环境、身体和注意依赖。

候选刺激不是感知结果，不能被认知或记忆当作角色经历。被遮挡、超出范围、感官不可用或未通过注意筛选的刺激可以在此阶段被拒绝。

### 4.5 结构化观察

结构化观察是感知系统提交的权威感知结果，表示角色在特定时刻实际获得了什么。它至少能够表达：

* 使用的感官通道或多通道组合。
* 观察到的对象类别、外在属性、动作或变化。
* 角色可以主观定位的空间来源或身体来源。
* 当前能够分辨的细节级别。
* 信息中的模糊、不完整或不确定性。
* 观察发生或持续的模拟时间关联。
* 与近期观察之间可被感知的连续、开始、变化或结束关系。
* 在满足识别条件时得到的最小主观身份关联结果。

结构化观察不包含完整世界实体、完整事件、隐藏原因、真实意图、调试标签或控制来源。

### 4.6 待处理感知流

待处理感知流保存已经形成、但尚未被对应认知流程确认消费的观察。它用于解耦感知形成与 LLM 认知调用，使清醒角色在暂时不需要运行 LLM 时仍能持续获得重要变化。

感知流不是无限事件日志。连续重复材料应先聚合或抑制，过时且已经被更新观察替代的内容应按配置折叠。消费状态必须明确，不能仅根据时间推测认知已经看到某条观察。

### 4.7 恢复上下文

恢复上下文是在明确认知中断结束时形成的一次性感知交接。它只描述恢复时仍能实际获得的环境、身体感觉、持续刺激和当前证据，以及角色能够主观察觉的连续或断裂。

恢复上下文不是中断期间的事件回放，不能包含已经消失的刺激、完整空档历史、施加者隐藏身份或中断的客观原因。

### 4.8 受保护诊断信息

受保护诊断信息记录材料来源、规则路径、被拒绝原因、内部实体锚点、状态版本、识别查询和重复抑制依据。它用于调试、审计和一致性检查，不属于角色感知。

授权工具可以读取诊断信息，但认知提示、普通记忆检索和世界内对话不能通过该渠道获得额外事实。

## 5. 抽象概念模型

### 5.1 感知实例

每个需要完整主观处理链路的 AI 角色关联独立感知实例。感知实例保存该角色的待处理观察、近期连续追踪、注意输入版本、恢复交接和去重状态。

用户正常实体拥有完整主观感知实例，并使用与 AI 正常实体相同的信息权限边界。控制来源不能改变其他角色观察用户角色时使用的材料、可达性和身份识别规则。

### 5.2 感官通道

感官通道表示一类获取信息的方式。具体世界可以定义视觉、听觉、触觉或其他通道，但名称本身不带固定算法。

通道是否可用及其效率由身体系统提供。感知系统负责把该结果与环境条件、距离、遮挡、材料特性和注意状态组合，决定最终能获得的信息。

### 5.3 不透明实体锚点

客观材料可以携带来源实体的唯一标识。感知系统把它作为不透明实体锚点，用于连续追踪、重复合并以及向记忆系统查询当前角色已有的主观身份关联。

不透明意味着感知和认知不能通过锚点自行读取实体的名称、人物设定、真实关系、认知、记忆或隐藏属性。锚点只是系统内部关联键，不是角色知道的名字或世界真相。

认知侧不接收可用于查询世界数据的实体标识。需要维持“仍是刚才那个人”的主观连续性时，感知系统提供仅对该观察者有效的观察引用或连续性描述。

### 5.4 观察对象连续性

观察对象连续性表示角色能够把当前观察与近期观察视为同一持续对象。其成立可以使用内部实体锚点和连续可见条件，但对外只表达角色能够实际察觉的连续性。

连续性不等于身份识别。角色可以持续跟踪一个不认识的人，也可以在对象消失、重新出现或条件显著变化后失去连续确认。

### 5.5 注意输入

注意输入由认知系统维护并提供，表示角色当前优先关注的对象、空间、通道或活动。感知系统使用注意输入筛选和排序材料，但不自行决定角色长期关注什么。

注意输入必须带有适用的认知状态版本。过时注意不能覆盖新的注意状态；缺少有效注意时，感知依据配置使用有限的默认环境注意，而不是把全部可达材料无差别提交给认知。

### 5.6 显著度

显著度表示某项刺激在当前条件下突破普通注意限制的能力。显著度来自材料属性、变化幅度、距离、身体感官修正和配置规则，不来自 LLM 临时解释。

高显著刺激可以被感知并形成建议唤醒，但不自动意味着危险、重要或值得采取行动。其意义仍由认知判断。

### 5.7 细节分辨率与可辨认程度

细节分辨率描述角色在当前条件下能够获得多少外在信息。可辨认程度描述这些信息是否足以尝试使用已有主观身份关联。

二者由距离、遮挡、环境、通道效率、注意、连续观察和材料配置共同决定。配置明确声明的遮蔽、伪装或其他辨认修正也可以降低可辨认程度。系统不要求生成或比较脸部、声纹和步态的自由文本特征。

细节分辨率决定当前可以形成实体轮廓、粗粒度类别和衣着，还是更完整的外在结构化描述。只有达到可尝试识别的分辨率后，感知系统才向记忆系统请求身份识别置信度；内部实体锚点本身不能提高该置信度。

### 5.8 主观身份关联

主观身份关联由记忆系统维护，表示当前角色是否已经把某个不透明实体锚点与自己的某个主观实体档案建立联系。

该档案可以包含角色已经获得或相信的称呼、类别、长期属性、印象、共同经历和主观关系，内容允许缺失、错误、冲突和过时。它是由 Recent 或 Long-term Memory 支持的物化主观知识视图，不是世界事实。

感知系统只查询形成识别表现所需的最小结果。低于识别阈值时不返回档案；达到阈值时只返回观察者本地的档案引用、当前首选称呼、确定性置信度及其自然语言等级。完整档案、关系背景和共同经历必须由认知通过 Memory Skill 按需检索，并接受 Working Memory 容量限制。

## 6. 输入材料与读取边界

### 6.1 世界材料

世界系统提供当前感知所需的最小客观材料，包括相关实体经过授权的外在事实、环境状态、空间关系、持续刺激和已经提交事件的可观察表现。材料保留权威事实值和不透明来源关联，但只包含实体感知投影允许引用的感知表面，不包含完整实体状态。

世界应按感知用途提供受限视图，而不是把完整状态或事件历史交给感知系统再依赖其自律过滤。世界负责保证输入事实真实且来自当前权威状态；感知系统依据观察者条件和投影定义决定其最终描述粒度。隐藏属性、控制来源和其他角色内部状态不得出现在普通感知材料中。

### 6.2 身体材料

身体系统提供感官通道可用性、效率修正、可以主观感受的身体材料，以及生成恢复上下文所需的受限身体转换来源。

精确身体指标、资源占用、阈值名称和隐藏致因不能直接转成角色感觉。身体材料应描述配置允许被感知的表现，感知系统再决定当前角色实际获得哪些内容。

### 6.3 当前状态与事件材料

当前状态材料用于回答此刻能够观察到什么，事件材料用于回答刚刚发生了什么可观察变化。两类材料可以共同形成观察，但不能互相替代。

只读取当前状态可能丢失短暂变化，只读取事件历史又可能把当时未被感知的事件事后补发。感知处理必须使用与观察时点一致的状态和事件边界。

### 6.4 最小读取原则

每次感知处理只读取与当前观察者、候选通道和触发材料相关的局部视图。感知系统不遍历完整世界，也不通过实体锚点请求对方完整人物数据。

用于识别、连续追踪和诊断的内部关联必须与认知可见内容分开保存和输出。

## 7. 感知处理流程

### 7.1 固定处理快照

一次感知处理开始时固定当前运行配置版本、世界感知材料版本、身体感官版本、注意状态版本和认知连续性状态。处理过程中出现的新变化进入后续处理，不得混入当前结果形成不一致观察。

### 7.2 建立候选刺激

系统根据新事件、状态变化、持续刺激到期检查、注意变化和恢复请求定位相关材料。没有变化且不需要重新检查的稳定材料不参与每次 Tick 的全量求值。

材料缺少必需来源、时间或版本关联时不能直接形成观察，应返回明确诊断。

### 7.3 可达性与通道筛选

对候选刺激检查位置、距离、空间关系、遮挡、环境条件、通道能力和身体感官修正。只有当前能够到达观察者感官的部分继续处理。

可达性规则可以复用统一规则内核。规则输出只是候选筛选结果，感知系统仍需验证材料类型、观察者归属和信息暴露范围。

### 7.4 注意与显著度处理

普通材料根据当前注意焦点、通道负荷和配置限制进一步筛选。与当前注意直接相关的材料优先保留；不相关且显著度不足的材料可以不形成观察。

达到配置显著条件的刺激可以突破当前注意，形成观察并向认知调度器输出建议唤醒原因。该结果不自动修改注意，也不直接调用 LLM。

### 7.5 细节与可辨认判断

感知系统根据剩余材料和有效条件计算本次可以表达的细节级别、不确定度和可辨认程度。结果必须保持单调的信息边界：较差条件不能产生只有较好条件才能获得的细节。

同一客观实体在不同条件下可以表现为清晰的人、看不清身份的人形轮廓或仅能定位的动静。具体措辞由渲染层决定，权威结果仍是结构化观察。

### 7.6 实体结构化描述投影

细节分辨率确定后，感知系统选择与实体材料类型匹配的感知投影定义，并按以下顺序生成结构化描述：

1. 只读取世界感知材料视图已经提供、且投影白名单明确允许的外在事实。
2. 按感官通道、环境前提和当前观察条件筛除不可用描述项。
3. 对每项事实选择不高于当前细节分辨率的最详细合法投影；没有合法投影时省略该项。
4. 把权威事实映射为感知领域词汇，并附上当前通道、粒度、不确定性、时间和变化关系。
5. 按配置声明的组合与稳定顺序合并类别、外观、姿态、动作、相对位置等描述。
6. 把来源实体标识保留在受保护元数据中，对认知只生成观察者局部引用。

例如，世界权威实体可以同时具有“实体类别、当前动作、外层颜色”、真实姓名和内部意图。感知材料视图只提供投影白名单允许引用的前三项；投影规则可以让低分辨率只产生“一个移动的轮廓”，中等分辨率产生“一个正在移动的人”，较高分辨率再加入允许观察的外层颜色。真实姓名和内部意图不会进入感知材料，因此在任何分辨率下都不会出现。

结构化实体描述至少能够包含：

* 仅对当前观察者有效的观察对象引用。
* 经过投影的对象类别和外在描述项。
* 可见姿态、动作、变化及相对空间信息。
* 每项描述实际使用的通道、分辨率和不确定性。
* 与前一观察之间的出现、持续、变化、消失或重新出现关系。
* 受保护的投影来源与规则追踪；该部分不进入认知。

投影失败、投影缺失或配置冲突时，感知系统不得把原始实体事实直接序列化为替代描述。它只能退化到仍有合法投影依据的更粗描述，或拒绝该材料并产生诊断。

### 7.7 主观身份关联查询

只有当前结果达到可辨认条件时，感知系统才可以使用观察者和不透明实体锚点查询记忆系统。查询只返回：是否存在当前角色自己的身份关联、可用于本次识别的最小主观称呼或引用，以及该关联所依赖的记忆状态版本。

存在关联时，观察可以表达角色认出了自己所认识的对象，例如“自称某个名字的人”。不存在关联时，观察只能表达一个不认识的人。当前条件不足时不得查询后再泄露名称。

查询不可用、超时或结果版本过时时，感知不能把对象断言为陌生人，也不能使用世界真实身份兜底；应形成身份未确认的有限观察，并保留诊断结果。

### 7.8 观察形成与提交

感知系统把通过验证的结果组织为结构化观察，检查其中每项内容均有当前材料和感知条件依据，然后提交到对应角色的待处理感知流。

一次处理可以合并同一来源、同一时段和同一变化的多通道材料，但不能因合并引入任一通道都无法支持的隐藏结论。

### 7.9 通知输出

观察提交后，感知系统可以输出新观察、重要变化、恢复交接就绪和建议唤醒等通知。通知只能引用已经提交的观察或当前有效条件，不能携带被过滤的客观材料。

## 8. 结构化观察与认知渲染

### 8.1 结构化实体描述

结构化实体描述由实体感知投影产生，是结构化观察中描述观察对象的部分。它使用感知领域词汇而不是世界内部字段名，不携带可解引用的世界实体标识。

同一个世界事实可以按不同分辨率映射为不同粒度的描述，多个世界事实也可以组合成一个感知描述。反向关系不成立：认知不能根据描述或观察引用无条件还原完整世界事实。

分辨率下降只限制当前能够形成的新描述，不会自动删除角色已经形成的记忆。认知是否利用过去记忆识别当前模糊对象，由记忆激活和认知判断决定，感知系统不能把记忆内容伪装成当前看清的事实。

### 8.2 有限观察而非原始信号

第一阶段不要求认知从亮度、声压或其他仿传感器数值重建日常对象。感知系统可以把材料组织为“门口有一个人形轮廓在移动”这类直接体验，同时保留看不清身份和细节的限制。

这种组织只描述外在对象和表现，不包括“正在偷听”“带有敌意”或“故意叫醒我”等因果、意图和意义判断。

### 8.3 不确定性

无法确定的内容必须以结构化不确定性表达，渲染时使用与之相符的措辞。系统不能为了生成流畅文本而把可能、模糊或未知改写成确定事实。

多个材料互相冲突时，感知可以并列保留可获得的差异，不能自行选择一个隐藏真相作为结果。

### 8.4 自然语言渲染

结构化观察是权威状态。自然语言渲染用于把选定观察放入认知上下文或展示给授权界面，不建立与结构化观察并列的第二份权威状态。

渲染使用稳定、受限的规则或模板，不调用 LLM，不增加结构化观察中不存在的身份、原因、情绪和意图。需要不同语言或表达风格时，可以更换渲染配置，但不能改变观察事实边界。

### 8.5 观察引用

认知需要引用当前观察对象时，使用仅对该角色有效的观察引用或主观身份引用。该引用可以支持“继续看着刚才那个人”等连续行为，但不能被用来直接查询世界实体完整状态。

## 9. 注意与认知唤醒

### 9.1 当前注意

认知系统维护注意内容及其变化，感知系统只应用当前有效输入。认知未产生新注意更新时，已有注意可以继续有效；没有新 LLM 调用不意味着注意或感知状态消失。

注意可以提高相关材料的处理优先级和细节，但不能让角色穿透遮挡、绕过感官禁用或获得不存在的客观材料。

### 9.2 默认环境注意

当角色清醒且没有明确注意焦点时，感知系统按配置维持有限的环境注意。默认注意不能等价于读取所有可达事实，应受到通道、范围、变化和容量限制。

### 9.3 显著中断

突发、强烈、接近或与当前活动直接冲突的刺激可以依据配置获得较高显著度。它们在通过感官可达性检查后可以突破普通注意筛选。

显著中断形成的是观察和建议认知原因。认知调度器仍需检查角色生命周期、身体参与许可、已有任务和去重，判断是否把该角色加入当前认知决策轮次。加入后，全局认知屏障必须在模拟继续推进前等待该角色完成决定。

### 9.4 无隐式意义

显著度是调度与注意属性，不是角色价值判断。高显著声音不自动表示威胁，低显著变化也不表示无意义。认知可以结合记忆和当前召回的多条意图形成不同理解。

## 10. 人物识别与主观知识边界

### 10.1 识别抽象

第一阶段把日常人物识别抽象为“当前感知分辨率是否允许尝试识别”“观察者是否仍有该实体的主观身份关联”以及“确定性识别置信度是否达到阈值”三个条件，不模拟生物特征匹配。

识别置信度使用感知分辨率、识别关联强度和可达性、连续观察、遮蔽和配置化伪装修正求值。普通换装只改变当前外在描述；只有明确配置的辨认修正影响身份置信度。该抽象允许表达熟人、陌生人、看不清身份和暂时无法确认的熟悉对象，同时避免为每个人编写可计算的脸部、声纹或步态描述。

### 10.2 第一次相遇

角色第一次清晰感知某个实体时，如果自己的记忆中没有身份关联，只能获得一个不认识的人及其当前可见表现。人物系统中的真实姓名、背景、人格和关系不会进入观察。

对方说出名字只是一次可听见的表达。感知系统可以记录说了什么，但不能替认知判断真假，也不能自行把该名字写入主观实体档案。

### 10.3 建立关联

认知系统可以根据自我介绍、他人说明、共同经历或其他证据形成身份认识，记忆系统再依据自身设计保存带来源的主观身份关联。该流程不属于感知系统。

身份关联可以指向错误称呼或错误认识。世界知道真实身份不会自动修正角色记忆。

### 10.4 再次识别

后续感知同一来源实体时，感知系统可以在当前分辨率允许的情况下查询已有主观身份关联。只有确定性识别置信度达到阈值，才能形成“认出这是自己所认识的某人”的观察；查询只加载本次识别需要的最小称呼、观察者本地档案引用和置信度，不加载完整实体档案。

认知需要共同经历、印象或关系背景时，应由记忆激活流程根据当前情境检索，不随每次感知自动附加。

### 10.5 识别限制

距离过远、遮挡严重、环境条件不足或感官受限时，即使存在身份关联也不能直接显示名称。观察连续性可以帮助角色保持对同一对象的跟踪，但不能在连续性已经丢失后无条件恢复身份。

通用伪装、冒充、仅凭单一特殊线索识别和复杂误认不属于第一阶段。未来若支持，应通过明确的可辨认规则和主观关联扩展，不能开放通过实体锚点读取真实身份的捷径。

## 11. 连续观察、聚合与去重

### 11.1 连续追踪

当来源实体持续可达且观察没有断裂时，感知系统可以维持同一观察对象的连续性。连续追踪帮助表达开始、持续、变化和结束，而不是每个 Tick 创建一个全新对象。

连续追踪状态属于短期感知状态，不是永久身份关系，也不能替代记忆。

### 11.2 变化检测

稳定存在且没有相关变化的材料不应反复生成同样观察。位置、动作、可见属性、识别状态或与当前注意有关的条件发生有效变化时，才形成更新观察。

变化检测必须基于已经提交的观察和当前材料版本，不能把被过滤的内部变化描述给认知。

### 11.3 聚合

短时间内属于同一来源和同一变化的多项材料可以聚合为一个观察。聚合应保留重要时间顺序和不确定性，不能把相互独立的事件合并成虚假的因果关系。

### 11.4 重复抑制

同一事件材料因重试、恢复或多个索引路径重复到达时，只能产生一次对应观察。重复抑制需要可识别的材料来源、观察关联和消费状态。

已经消费的观察不会因恢复运行再次进入待处理感知流；尚未消费但被新观察取代的内容可以按配置折叠，并保留必要连续关系。

## 12. 认知连续与中断恢复

### 12.1 清醒但未调用 LLM

角色处于认知连续状态时，即使多个 Tick 没有运行 LLM，感知系统仍然可以形成观察、维护连续追踪并把需要处理的变化加入感知流。

认知调度器可以依据新观察决定是否运行，也可以让低重要度观察等待后续周期。等待不等于角色失去意识或出现记忆空档。

这一普通连续语义不适用于 Fast Forward 中被明确离屏的非主要正常实体。快进期间系统级禁止 LLM，这些实体的新认知需求不会排队等待补算；未消费观察只能按确定性离屏策略折叠、失效或删除。

### 12.2 明确认知中断

只有认知连续性明确进入睡眠、失去意识或其他中断状态时，感知系统才停止形成普通可事后消费的主观观察。

中断期间仍可以对配置允许影响身体模式、认知参与许可或唤醒条件的刺激进行确定性检测。该检测结果用于身体和调度协作，不自动成为角色经历。

### 12.3 恢复上下文生成

认知连续性恢复时，感知系统根据恢复时的世界材料、身体材料、持续刺激和中断前有效交接生成一次恢复上下文。

恢复上下文可以包含当前仍在响的声音、仍在发生的触碰、当前疼痛或不适、醒来后可见的环境状态，以及角色能够察觉的状态断裂。它不能包含已经结束的声音、空档中的完整事件顺序、谁实施了隐藏行为或系统记录的客观致因。

### 12.4 一次性交接

恢复上下文与明确的中断边界和状态版本关联，只能被对应恢复认知周期消费一次。普通清醒状态下的调度间隔不生成恢复上下文。

如果恢复前条件再次变化或重新进入中断，旧恢复上下文必须重新验证或失效，不能覆盖新的连续性状态。

Fast Forward 为非主要正常实体建立的离屏空档不是身体认知中断。它不生成睡醒式恢复上下文，也不能告诉角色其认知被系统跳过。退出快进后，感知只从当前实际可获得的材料继续，不回放空档观察。

## 13. 更新边界与确定性

### 13.1 触发式处理

感知处理由相关世界事件、身体变化、注意更新、持续刺激检查、认知恢复请求或显式查询触发。系统不要求每个 Tick 对整个世界和全部实体进行扫描。

### 13.2 Tick 边界

感知可以在统一调度定义的稳定阶段读取已经提交的世界与身体版本，并在自身提交阶段形成观察。它不能读取其他系统尚未提交的中间状态。

具体跨系统阶段顺序由时间与整体调度系统统一定义：世界与身体达到本 Tick 的客观稳定状态并解决规则屏障后，感知才读取已提交版本；感知完成后才允许建立认知屏障。感知系统仍要求输入版本一致、结果提交原子且通知发生在提交之后。

普通连续和 Fast Forward 使用相同固定 Tick。Fast Forward 可以只执行主要实体恢复检查、离屏观察折叠及其他明确需要的确定性感知处理，但不能通过降低展示频率跳过会影响主要实体认知许可或恢复上下文的材料。

### 13.3 无 LLM 和隐藏输入

感知处理和渲染不调用 LLM，不使用机器时间、随机数、未声明的外部数据或任意脚本。需要参与筛选的时间必须是显式模拟时间。

相同运行配置、相同输入快照和相同已有感知状态应产生相同结构化观察、顺序和诊断结果。

### 13.4 配置更新

感知配置通过统一原子配置更新生效。已经开始的单次处理使用开始时取得的配置快照完成；更新后开始的处理使用新配置。

配置更新不能倒改已经形成并被消费的观察。未消费观察保持其形成时的内容和来源，后续是否折叠或失效必须使用明确规则并保留可追踪原因。

## 14. 跨系统协作

### 14.1 与世界系统

世界系统维护客观事实、空间关系和事件历史，并提供用途受限的感知材料视图。感知系统不能直接修改世界，也不能把完整世界状态复制为观察。

世界中的来源实体标识只作为受保护锚点进入感知处理。世界真实身份和隐藏状态不会因该锚点存在而成为角色知识。

### 14.2 与身体系统

身体系统提供感官可用性、效率修正、身体事件材料及受限恢复来源。感知系统决定这些材料中哪些成为角色实际感觉。

身体指标变化不等于角色感知到精确数值；感知结果也不能反向覆盖身体状态。身体参与许可和感知结果使用的版本必须保持一致。

### 14.3 与人物系统

人物系统关联角色与感知实例，并提供不含控制来源的公开角色关联。人物 Identity 不是其他角色感知结果的直接数据源。

用户角色与 AI 角色作为观察对象时使用相同材料和规则。用户控制标签、输入来源和内部代理差异不得进入观察。

普通动态实体没有自主感知决策入口；降级实体在其世界更新基础上增加行为树，并使用人物、世界和身体共同提供的用途受限局部执行视图。该视图不形成结构化主观观察，也不能读取完整 Ground Truth。正常实体以完整感知、认知和记忆链路替换行为树及其局部视图。主要标记和能力层级均不得进入其他角色观察。

### 14.4 与认知系统

认知系统提供当前注意，并消费结构化观察或其受限文本渲染。感知系统不替认知解释原因、判断真假、形成意图或接受身份声明。

认知可以引用观察对象、更新注意或请求查看当前可感知信息，但不能借观察引用读取隐藏世界状态。

### 14.5 与认知调度

感知系统在新观察、显著中断或恢复上下文就绪时提供建议唤醒。建议包含最小原因、观察关联和依赖版本，不携带被过滤信息。

认知调度器负责合并、去重和验证建议，并据此建立当前模拟时间点的认知参与者集合。感知系统不能绕过调度器直接调用 LLM，也不能自行解除全局认知屏障。

Fast Forward 中感知建议只能使主要实体结束快进并进入普通认知流程。非主要正常实体的普通建议不建立屏障、不调用 LLM，也不保留为退出后的待补算轮次。

### 14.6 与记忆系统

感知系统可以在达到可尝试识别的分辨率后，使用观察者、不透明实体锚点、当前分辨率、连续观察和辨认修正查询最小主观身份关联。记忆系统确定性计算识别置信度；内部实体锚点本身不构成置信度来源，也不能使低分辨率观察泄漏身份。

达到阈值时，记忆系统只返回观察者本地档案引用、首选称呼、数值置信度和自然语言等级。完整主观档案及相关经历必须由认知通过 Memory Skill 检索，感知系统不能自动附加。

已经提交的结构化观察必须先通过 Working Memory 容量准入，才能被认知使用或成为编码候选。候选刺激、被过滤材料、诊断追踪和中断期检测不能作为普通记忆材料。

身份关联的建立、修正、遗忘、冲突处理及相关知识激活留给记忆系统详细设计。

### 14.7 与统一配置与规则基础设施

感知系统复用统一配置的命名空间、引用、组合、版本、验证和原子更新能力。实体感知投影、确定性的可达性、阈值、显著度、细节映射、描述粗化和材料筛选可以复用规则内核。

共享基础设施只产生候选筛选或映射结果，不能直接提交观察、写入感知流、调用记忆或触发认知。感知系统负责领域验证和最终提交。

### 14.8 与配置生成 Skill

配置生成 Skill 未来可以生成感官通道、材料类型、筛选、显著度、分辨率和渲染配置。生成结果必须通过共享验证与感知领域验证。

Skill 不能通过配置把人物真实身份、控制来源或完整世界状态声明为普通可感知内容。本阶段不创建该 Skill。

## 15. 产品级概念接口

以下接口只定义交互责任和产品语义，不规定字段、协议或调用方式。

### 15.1 感知实例创建与加载

接收有效感知配置和角色关联，建立感知实例、初始通道状态、空的感知流及连续追踪状态。创建失败需要区分配置错误、角色关联无效、身体视图不可用和版本不兼容。

### 15.2 感知配置验证

验证材料类型、通道引用、实体感知投影、可达性规则、注意与显著度策略、分辨率映射、聚合、去重和渲染规则。验证必须保证所有投影来源都来自授权感知材料、每项输出都有合法分辨率、粗化路径可以确定、多来源组合无歧义，并且配置不能读取隐藏状态或输出禁止信息。

### 15.3 客观材料接收

接收世界和身体提供的材料及其状态版本、模拟时间和受保护来源关联。材料进入候选流程，不因接收成功自动成为观察。

### 15.4 注意状态更新

接收认知系统提供的当前注意及认知状态版本。过时更新不能覆盖较新的注意，缺少有效注意时使用受限默认策略。

### 15.5 实体感知投影

接收已经通过世界感知材料视图授权的实体外在事实、当前细节分辨率和有效观察条件，返回使用感知领域词汇表示的结构化实体描述及受保护追踪。接口没有通用实体解引用或原始对象序列化能力。

### 15.6 感知处理

针对相关候选刺激执行可达性、感官、注意、显著度、分辨率、识别和观察形成流程，返回已提交观察、被拒绝原因及建议通知。

### 15.7 主观身份关联查询

向记忆系统提交观察者、不透明实体锚点、当前感知分辨率、连续观察、辨认修正和依赖版本。低于识别阈值时返回未识别；达到阈值时只获得观察者本地档案引用、首选称呼、数值置信度和自然语言等级。接口不得提供世界实体解引用、完整档案或共同经历读取能力。

### 15.8 感知流查询与消费确认

为认知流程提供尚未消费且仍有效的结构化观察，并在认知成功接收后显式确认消费。查询本身不应隐式删除观察，失败、取消或保存恢复中断的认知决策轮次也不能错误确认消费。

### 15.9 建议唤醒

向认知调度器提供由新观察、显著刺激或恢复交接产生的建议。调度器可以接受、合并或拒绝；接受后必须把对应角色加入当前认知参与者集合，并在模拟继续前完成本轮决定。感知系统不自行调用模型或推进时间。

### 15.10 恢复上下文生成与消费

依据明确的认知中断边界和恢复时有效材料生成一次性恢复上下文，并与对应连续性版本绑定。消费、失效和重建必须可追踪。

### 15.11 观察渲染

把选定结构化观察稳定转换为认知可读文本。渲染只能使用观察已有内容，不能补充身份、因果、意图、情绪或未经观察的背景。

### 15.12 诊断查询

为授权工具提供材料来源、筛选路径、内部锚点、版本、识别查询和去重依据。诊断视图与角色运行时输入严格隔离。

### 15.13 保存与恢复

保存未消费观察、消费标记、近期连续追踪、内部锚点关联、注意输入版本、重复抑制状态、恢复交接和所依赖配置版本。恢复时核对世界、身体、人物和认知连续性关联，不能重复生成或交付观察。

## 16. 结果、失败与一致性语义

### 16.1 观察提交结果

感知处理需要区分已形成新观察、更新已有连续观察、被注意过滤、不可达、通道不可用、材料无效、身份未关联、身份查询不可用、版本过时和无需产生变化等结果。

“身份未关联”表示角色当前没有相应主观认识；“身份查询不可用”表示系统无法确认，二者不能合并为同一陌生人结论。

### 16.2 版本一致

观察必须关联形成时使用的世界、身体、注意、认知连续性、记忆身份关联和运行配置版本。延迟查询或过时结果不能覆盖更新后的观察。

### 16.3 提交原子性

一条观察只有在内容验证、连续关系、去重状态和感知流更新全部成功后才可见。失败不能留下半条观察、已经占用的消费标记或不完整连续追踪。

### 16.4 信息不升级

任何错误、缺失依赖或服务不可用都不能使用完整世界事实兜底。系统宁可保留未知、模糊或未确认，也不能把内部真相升级为角色知识。

### 16.5 效果不重复

相同来源材料、恢复交接或认知消费确认必须具有可识别关联。重试、加载和恢复不能重复生成观察、重复发出一次性恢复上下文或重复确认消费。

## 17. 保存与恢复

### 17.1 保存内容

感知快照至少覆盖：

* 感知实例与角色关联。
* 尚未消费的结构化观察及形成版本。
* 已消费观察的必要去重标记。
* 当前观察对象连续性和受保护锚点关联。
* 当前注意输入版本及适用状态。
* 持续刺激和聚合窗口所需的最小状态。
* 尚未消费或失效的恢复上下文。
* 当前运行配置版本和必要诊断关联。

### 17.2 恢复核对

恢复时必须确认角色、世界、身体、认知连续性和记忆关联仍然属于同一保存边界。无法确认的一致性不能通过猜测修复。

观察对象已经不存在或连续条件已经失效时，应结束对应短期追踪，但不能删除已经被角色获得且仍待认知消费的合法观察。

### 17.3 时间线边界

从较早快照恢复后，原时间线后续形成的观察、消费确认和恢复交接不能继续影响当前状态。未来如支持分支时间线，应由整体保存和实验管理另行设计。

## 18. 验收场景

1. 陌生实体第一次清晰出现时，角色只获得一个不认识的人及当前可见表现，不会读取其姓名、背景或人物设定。
2. 对方自称某个名字时，感知只记录一次表达；是否相信和保存由认知与记忆决定。
3. 角色建立主观身份关联后再次清晰遇见同一实体，可以认出自己所认识的对象。
4. 主观身份关联来自假名时，识别继续反映该错误或未验证认识，不会自动显示世界真实姓名。
5. 距离过远、遮挡严重、环境不足或感官受限时，即使存在身份关联也不能直接识别。
6. 身份查询服务不可用时，系统输出身份未确认，而不是断言陌生或读取世界身份兜底。
7. 感知可以持续追踪刚才看到的同一个人，但不会因此获得其身份或完整资料。
8. 一个实体在良好条件下表现为清晰的人，在较差条件下可以只表现为人形轮廓或无法确认的动静。
9. 结构化观察中的不确定内容在文本渲染后仍保持不确定，不会被改写为确定事实。
10. 感知不会把外在动作直接解释为敌意、欺骗、故意或其他高层意义。
11. 当前注意范围内的普通变化可以形成观察，注意外的低显著稳定材料不会全部涌入认知。
12. 高显著刺激可以突破当前注意并产生建议唤醒，但不会直接启动 LLM。
13. 清醒角色连续多个 Tick 没有调用 LLM 时，仍能形成感知并保持认知连续性。
14. 睡眠或昏迷期间的刺激可以参与唤醒检测，但不会在恢复后形成完整空档回放。
15. 恢复时仍在响的声音、持续触碰、当前疼痛或可见环境状态可以进入恢复上下文。
16. 已经消失的刺激、施加者隐藏身份和中断的客观原因不会通过恢复上下文泄漏。
17. 稳定站立的同一对象不会每个 Tick 重复生成同样观察，其有效移动或状态变化可以形成更新。
18. 同一事件材料重试、重复索引或恢复后再次到达时不会产生重复观察。
19. 认知失败或过时周期不会错误确认观察已消费，成功消费后恢复运行也不会再次交付。
20. 用户角色和 AI 角色作为被观察对象时使用相同规则，控制来源不会出现在观察中。
21. 认知只得到本次识别所需的主观称呼或引用，完整主观实体档案不会随每次感知自动加载。
22. 配置更新不会倒改已经形成或消费的观察，新处理统一使用更新后的当前配置。
23. 保存恢复保留未消费观察和连续追踪，同时不会重复交付观察或恢复上下文。
24. 一个实体只有被感知投影白名单允许的外在事实可以进入结构化描述，未声明字段不会被自动序列化。
25. 同一组实体事实可以在不同分辨率下稳定产生轮廓、类别和更细外在属性等不同粒度的描述。
26. 低分辨率投影缺少某项细节时，系统选择已声明的粗化描述或省略，不会使用完整事实兜底。
27. 真实姓名、内部意图和控制来源即使存在于其他权威系统，也不能通过提高分辨率进入实体描述。
28. 实体外在事实发生变化时，只对已经进入观察且满足当前分辨率的描述生成相应变化，不泄露被过滤字段。
29. 投影引用未授权事实、分辨率路径存在歧义或多来源描述没有组合方式时，感知配置不能加载。
30. 内部实体锚点相同但识别置信度不足时，感知仍只返回当前分辨率允许的模糊描述。
31. 感知分辨率可以随光线、距离、遮挡和感官效率变化，身份识别置信度在允许尝试识别后单独求值。
32. 普通换装只改变当前外在描述，不创建新的主观实体档案；明确伪装或遮蔽可以降低识别置信度。
33. 识别成功只返回观察者本地档案引用、称呼和置信度，完整属性、关系及经历仍需记忆检索。
34. 已提交观察未通过 Working Memory 容量准入时，不会绕过记忆系统直接进入认知或持久记忆。
35. Fast Forward 中非主要正常实体的未消费观察会按确定性策略折叠、失效或删除，退出后不回放。
36. 离屏空档不会被错误生成睡醒式恢复上下文或成为角色知识。
37. 降级实体行为树的局部执行视图不被伪装成结构化主观观察，也不能读取完整世界状态。

## 19. 范围边界

本文保持具体世界和技术实现无关，不定义：

* 具体世界采用的感官名称、距离、阈值、容量、显著度和数值平衡。
* 具体角色、外貌、声音、地点、物品、事件和自然语言模板内容。
* 真实计算机视觉、音频处理、声纹、脸部、步态或其他生物特征识别。
* 通用伪装、冒充、幻觉、错觉及复杂跨通道误认算法。
* 主观实体档案的完整结构、更新、遗忘、冲突、检索和巩固算法。
* 认知提示词、LLM 调用、理解、推理、情绪和意图形成。
* 记忆编码、相关记忆激活、认知在同一次决策调用中对记忆片段的内联解释和长期关系演化。
* 用户界面如何向真人用户展示世界，以及用户输入设备的感知模型。
* 具体数据结构、协议字段、数据库、消息队列、部署和性能技术。

这些内容应在认知、记忆、时间调度、具体内容设计或后续工程设计中分别确定。

## 20. 设计约束总结

感知系统的核心约束如下：

1. 感知把客观材料转换为角色实际获得的有限结构化观察，不复制完整 Ground Truth。
2. 世界、身体、感知、认知和记忆分别维护自己的权威状态。
3. 实体感知投影以显式白名单把授权外在事实映射为不同分辨率的感知描述，禁止通用序列化实体状态。
4. 结构化观察是权威结果，自然语言只是稳定渲染，不得增加隐藏信息。
5. 感知可以组织日常对象和外在表现，但不判断因果、意图、真假和意义。
6. 不透明实体锚点只用于连续追踪、去重和最小身份关联查询，不能解引用人物设定。
7. 人物识别先计算感知分辨率，再结合主观身份关联、连续观察和辨认修正确定性计算识别置信度，不模拟自由文本生物特征匹配。
8. 第一次相遇不会自动获得身份知识，自我介绍仍需经过认知和记忆流程。
9. 身份关联可以错误、缺失或过时，世界真实身份不会自动纠正角色认识。
10. 当前注意限制普通输入，高显著刺激可以突破注意但只能产生建议唤醒。
11. 没有 LLM 调用不等于认知中断；明确中断期间不会形成可事后回放的普通经历。
12. 恢复上下文只包含恢复时仍可感知的刺激、身体感觉和当前证据。
13. 连续追踪、变化检测、聚合和重复抑制避免稳定场景在每个 Tick 重复进入认知。
14. 感知处理确定性运行，不调用 LLM、随机数、机器时间或任意外部 I/O。
15. 观察、消费、识别查询和恢复交接均受状态版本约束，过时结果不能覆盖新状态。
16. 诊断、内部锚点、控制来源和被过滤材料始终与角色运行时信息隔离。
17. 已提交观察仍需通过 Working Memory 容量准入，感知成功不等于角色能够同时在认知中保留全部观察。
18. Fast Forward 中非主要正常实体不积累待补算观察，退出后只从当前可感知状态继续。
19. 普通动态实体不具备自主感知入口；降级行为树局部执行视图与正常实体主观感知严格分离。
