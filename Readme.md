# AI伙伴角色实验系统设计

## 1. 项目目标

构建一个具有持续生活、独立行为和个人经历的 AI 伙伴，使用户能够通过自然聊天与共同活动，逐渐形成独特的伙伴关系。

系统不以任务执行或剧情推进为中心，而是通过角色认知、身体行动、世界反馈与记忆演化，形成持续的个人经历和共同经历。

交互形式为纯文本，世界观为虚构世界，聊天与共同活动并重。

## 2. 总体架构

运行时系统由统一配置与规则基础设施、世界、角色、身体、感知、认知、记忆和时间调度组成；降级实体另外使用满足系统适配契约的第三方确定性行为树。设计时由配置生成 Skill 将带有明确字段语义的世界观与角色自然语言资料转换为结构化候选配置或初始记忆候选。

实体能力采用递进模型：普通动态实体提供世界状态和确定性更新；降级实体在此基础上增加身体执行、确定性行为树和有限黑板；正常实体保留相同世界、身体和生命周期基础，但用完整感知、认知与记忆链路替换行为树决策模块。一个实例不能同时运行行为树和完整认知两套自主决策器。

基本运行闭环：

**世界与身体更新 → 角色感知 → 认知决策 → 产生意图 → 身体执行 → 世界反馈 → 形成经历**

世界与身体持续运行，LLM 按需参与认知，不直接控制世界状态。

## 3. 统一配置与规则基础设施（Configuration & Rule Infrastructure）

统一配置与规则基础设施为各运行时子系统提供共同的配置和声明式规则能力，避免世界、人物、身体及后续子系统分别实现结构相似但互不兼容的解析器、验证器和规则引擎。

配置基础能力包括类型与结构约束、默认值、组合与覆盖、引用解析、命名空间、版本标识及统一验证。人物配置可以引用身体模板，身体模板可以组合器官、能力、指标和效果映射，具体子系统不需要重复实现这些通用机制。

规则基础能力包括受限条件、触发器、效果映射、持续过程、依赖关系、组合运算、编译、索引和确定性求值。阈值、分段常量、分段线性及未来增加的通用规则表达应在共享基础设施中实现一次，并供有需要的子系统复用。

各子系统仍然拥有自己的领域语义和权威状态。世界、人物、身体、感知、认知或记忆系统分别注册自己允许读取的视图、条件词汇、效果类型和领域验证；统一基础设施只对声明进行解析、验证和求值，不能绕过子系统接口直接修改其权威状态。

共享能力通过版本化的通用内核和领域扩展逐步增强。新增运算、映射或调试能力应优先扩展基础设施并保持现有配置语义兼容，而不是在单个子系统中创建另一套近似机制。

规则运行必须确定、可追查且不执行任意代码。LLM 或配置生成 Skill 可以生成候选配置与规则，但只有通过共享结构验证和对应子系统领域验证后才能加载；运行时 Tick 不调用 LLM 来解释已经加载的规则。

该子系统的详细设计见[统一配置与规则基础设施设计](docs/configuration-rule-infrastructure.md)。详细设计确立“配置能力必须复用、规则能力按需复用”、单一运行配置版本、配置更新原子生效以及确定性求值内核不使用随机运算或 I/O 等原则。

## 4. 世界系统（World）

世界分为静态设定与动态状态。

静态设定包含世界观、环境氛围、基础规律、地点及物品类型。

动态状态包含角色位置、物品状态、环境变化及正在发生的事件。

角色与动态物品拥有独立的更新生命周期，共享统一的世界时间。

世界负责实际行动结果、状态一致性及客观事件记录。

支持开放式行动意图，不要求每一种自然生活行为都具有独立的硬编码动作接口。

简单行动可以根据通用规则执行；具有不确定结果的行动需要独立的环境反馈。

角色不能通过语言叙述直接修改世界事实。

## 5. 角色系统（Character）

每个角色包含：

* **Identity：** 身世、个人历史、人格、偏好、自我认识。
* **Body：** 身体能力、器官、资源占用及行动状态。
* **Perception：** 通过身体感官获取有限的世界信息。
* **Cognition：** 维持当前认知状态，形成和调整意图。
* **Memory：** 保存角色视角下形成的记忆和经验。
* **Continuity：** 保存未结束的意图、活动及持续性决定。

上述完整主观链路适用于正常实体。实体能力层级与主要地位分别配置：正常实体不会自动成为主要实体；主要标记只表示整体调度需要等待其意识判断，不属于世界事实。

降级实体是普通动态实体的超集，但不创建完整感知、认知、Working Memory、Recent Memory 或 Long-term Memory，只通过确定性行为树读取受限局部世界视图、自身身体状态和有限黑板，并提交普通短身体计划。正常实体则以完整主观链路替换该行为树和黑板。普通动态实体和降级实体都必须是非主要实体；降级计划仍接受与正常实体相同的身体能力、资源冲突和世界规则。

角色具有认识用户之前的个人历史，但与用户的共同经历必须通过实际互动形成。

Identity 中的个人历史是角色定义和认知背景，不会在人物创建时自动拆成可检索情景记忆。配置生成 Skill 只有在初始记忆模式中接收到明确标记为合格角色经历、对话或世界内记录的字段时，才会生成带来源的初始记忆与实体档案候选，再交由记忆系统验证。

角色只能通过感知、记忆和外部信息了解世界，不能直接读取完整世界状态或其他角色的内部状态。

## 6. 身体与行动系统（Body）

正常实体由认知 LLM 或用户输入形成意图，降级实体由确定性行为树形成简单计划，身体统一负责验证和执行；普通动态实体没有自主计划来源。

初期身体能力包括说话、行走、手势、拿取、放置和简单物品操作。

行动根据器官占用、身体能力、环境条件及资源限制进行执行。

兼容行动可以并行，存在资源冲突的行动不能同时执行。

行动具有开始、进行中、完成、中断和失败等状态，可以持续多个 Tick。

身体系统自行推进能够确定执行的动作，无需每个 Tick 调用 LLM。

身体与认知独立运行。角色没有进行认知处理时，身体仍持续存在、推进既有动作和身体过程，并能够受到其他角色及环境的影响。

身体通过可配置指标及效果映射表达体力、身体完整度、唤醒能力等状态。指标可以使用阈值、分段常量或分段线性方式影响能力、资源、感官效率及认知参与许可；具体指标、区段、曲线、消耗和恢复规律由世界及身体模板配置决定，不由引擎硬编码。

身体状态可以限制或禁止认知参与，但身体变化不代表角色已经感知、理解或记住相关事件。

睡眠、昏迷和麻醉不是调度器设置的固定时长定时器。身体在固定 Tick 中继续推进恢复、恶化和外部刺激，并依据当前状态重新计算认知参与许可；声音、触碰、疼痛或光线必须先经过世界与身体规则，不能由调度器按标签直接唤醒。

行动结果通过感知系统反馈给角色认知。

## 7. 认知系统（Cognition）

认知是持续存在的状态，而不是每次调用 LLM 时重新生成的完整角色状态。

认知系统维护当前注意力、主观理解、疑问、多条前瞻性意图、持续性决定及认知连续性。当前认知状态只保存下一次认知需要延续的最小内容；意图使用独立的前瞻性状态，理解、疑问和理由可以是自然语言，结构只用于明确类型、来源和生命周期。

不要求所有行为都具有明确的 Goal。

角色可以直接形成即时方向，也可以保有多条跨轮次意图。意图不是必须追寻的任务：系统只召回当前相关意图，认知 Agent 结合 Identity、观察、记忆和身体状态自行决定行动可以服务一条、多条或不服务任何既有意图。

长期决定具有持续性，不因注意力转移或新一轮 LLM 调用而自动失效。

已经接受的共同约定应能够影响后续实际行动，同时允许角色根据新情况调整或取消决定。

认知与身体执行职责独立：没有新决策需求时，身体和世界自行推进已有动作；出现需要角色反应或选择的稳定边界时，模拟暂停并完成认知决定，然后再继续推进。

AI 角色的一次认知 LLM 调用同时形成必要的认知状态更新、表达内容和短身体计划，不固定增加第二次 LLM Pass。认知决定经过格式、来源和权限验证后提交；身体计划仍由身体系统独立验证和执行。

模型实际返回的原始响应及其结构化决策追踪可以作为受保护诊断保存，但不属于角色认知或记忆，不能自动回灌为后续角色知识。系统不要求或伪造供应商没有返回的隐藏推理过程。

### 7.1 自主意图的形成

自主意图可以来自：

* 身体状态与内部需求。
* 稳定偏好与个人历史。
* 当前感知到的环境机会。
* 已有意图、持续性决定及共同约定。
* 过去经历形成的兴趣、疑问与经验。

角色不必因身体空闲而立即产生新意图。

允许休息、等待、观察和不采取新行动，但 AI 没有立即行动时必须建立可验证的外部事件等待、确定性重审条件或具有后续决策边界的持续活动。等待期限由规则求值并受全局硬上限约束，到期只触发重新认知，不强制继续旧意图或采取动作。

经历可以改变角色未来的关注、偏好和行动选择，但不要求每次行动都形成新目标。

未完成意图依据当前实体、地点、事件、身体状态、观察、Working Memory 和语义线索进行前瞻性召回，并使用 Working Memory 的配置化预留容量。召回只决定角色能够想起哪些意图，不能替角色完成意图竞争。只有认知确认实际考虑或追随的意图才得到强化；长期未使用意图可以衰减并遗忘，遗忘本身不会自动生成长期记忆。

## 8. 认知调度

系统采用离散模拟，模型调用和用户等待消耗的现实时间不计入模拟时间。世界与身体的确定性 Tick 不调用 LLM，但一次完整模拟轮次可以在 Tick 产生感知和认知需求后进入认知阶段。

当当前稳定时间点存在必须解决的认知需求时，整体调度建立全局认知屏障。在所有必要 AI 角色完成认知决定、所有必要用户角色输入或跳过之前，不开始下一个世界或身体 Tick。

认知调用由以下条件触发：

* 出现需要理解或回应的新感知。
* 当前行动完成、失败、中断或需要新的决策。
* 既有决定的条件发生变化。
* 内部状态产生值得关注的变化。
* 已接受决定登记的明确模拟时间或其他可确定关注条件到达。

多个 AI 角色的 LLM 调用可以在现实计算层并发执行，但它们读取同一模拟快照，不能看到其他角色本轮尚未提交的决定。模型返回顺序不产生模拟优先级；全部必要参与者完成后，本轮身体计划才统一交给身体系统。

系统不设置固定周期思考，也不允许没有明确承诺或外部条件的自由认知预约。认知提交并经规则限制的有限等待期限属于明确重审条件，不是全局周期思考。身体动作完成不必自动触发完整认知；身体空闲、Tick 推进和现实时间流逝都不构成唤醒理由。

动作执行期间默认保持认知静默。新对话、高显著刺激、动作结果、前提变化或明确决策点可以在合法稳定边界建立认知屏障。认知决定本身不自动停止当前动作；新动作继续通过并行、排队或替换策略接受身体系统验证。

身体侧有限动作阶段可以使用工作量与有效执行速率确定性推进；瞬时、持续保持和等待外部条件的阶段使用各自明确完成条件。认知系统只消费阶段结果，不计算动作工期。

用户角色到达需要认知判断的边界时，用户本人替代自主认知 LLM。模拟暂停等待用户输入或明确跳过；用户自然语言意图由输入解释 LLM 转换为与 AI 角色相同语义的表达和身体计划，并接受相同的身体能力、资源及世界规则。跳过本轮不取消已有动作或长期事项。

主要实体标记是正常实体上的独立调度属性，不由 AI 或用户控制来源、认知内容或世界身份自动推出；普通动态实体和降级实体不具备主要资格。普通模式下，主要和非主要正常实体都可以参与认知；Fast Forward 中系统禁止所有 LLM，非主要正常实体的新认知需求直接按离屏策略丢弃，不阻塞快进，也不会在退出后补算经历。

该子系统的详细设计见[认知系统与认知调度设计](docs/cognition-system.md)。

## 9. 记忆系统（Memory）

记忆系统模拟有限感知、选择性编码、信息遗失和主观回忆，而非将完整客观历史直接提供给角色。

### 9.1 Ground Truth

世界独立保存完整客观事件，包括实际行动、对话和状态变化。

Ground Truth 不属于角色记忆，不能在普通认知与记忆检索中被直接读取。

角色可以通过实际感知、外部记录或其他角色提供的信息重新获得过去的事实。

### 9.2 Working Memory

Working Memory 维护当前认知直接可用的结构化认知块，不等同于完整 LLM Context，也不复制认知系统维护的注意、疑问、意图和持续性决定。相关意图只能以指向认知权威状态的激活引用进入预留容量。

所有新观察、认知产物和检索结果都必须先通过 Working Memory。其容量和离散负荷由确定性规则求值；未使用内容快速衰减并真实删除，退出不会自动形成持久记忆。

### 9.3 Recent Memory

Recent Memory 保存角色从实际使用的 Working Memory 内容中选择性编码的近期经历，不直接复制完整世界事件。

Recent Memory 没有容量上限，以配置化时间窗口管理。超窗仍未巩固的内容从运行时永久删除；删除数据可以进入受保护审计归档，但不再允许角色记忆或 Agent 访问。

### 9.4 Long-term Memory

通过选择性巩固形成长期情景记忆、知识、经验及关系记忆。

保留角色自己关注的内容及其主观理解，不要求完整、准确地复现客观历史。

不同角色对同一事件可以形成不同的记忆。

单条近期痕迹可以迁移为长期状态，多条近期痕迹可以归纳为新的长期结果。巩固成功后相应内容退出 Recent Memory，不在两个活动层保存重复副本；巩固允许概括、失真和细节丢失。

### 9.5 记忆片段的内联解释

记忆检索通过受限 Memory Skill 进行。认知 Agent 可以在预算内形成和调整查询，但只能获得已经通过权限、状态、相关性、可达性和 Working Memory 容量限制的内容。

记忆系统返回带来源的有限片段，不建立独立“主观回忆重建”Agent、处理阶段或持久对象。记忆 Agent 的受限重排只能组织已有候选，不能创造完整回忆叙事。

认知 Agent 在形成行动决定的同一次 LLM 调用中处理片段缺失、冲突、模糊和不确定性，并形成角色自己的临时解释。临时解释可以影响当前判断，但不能把无来源细节伪装成检索结果，也不会自动成为新的记忆或覆盖原始痕迹。

只有认知明确提交新的反思、判断或关系认识，并引用本轮实际消费的记忆片段且通过编码验证后，才会形成新的 Recent Memory。通过后续实际感知获得的新证据，可以继续修正角色对过去的认识。该过程不增加额外认知 LLM Pass。

### 9.6 主观实体认知

每个 AI 角色分别维护对人物、物品、地点及其他可识别实体的主观档案。档案保存角色相信的称呼、类别、长期属性、印象、关系和共同经历引用，可以错误、冲突或过时，不属于世界事实。

世界实体标识只作为受保护的不透明锚点。感知系统必须先根据光线、距离、遮挡、感官效率和伪装修正确定感知分辨率，再由记忆系统结合识别关联计算确定性识别置信度。达到阈值时只返回观察者本地的最小档案引用、称呼和置信度；完整背景仍需通过记忆检索并进入 Working Memory。

### 9.7 混合检索

记忆相关性与可达性分别计算。结构索引、记忆关联图、必需但可替换的语义相似度能力和当前情境共同形成查询相关性，再与基础可达性及抑制组合为综合激活。

只有超过召回阈值的有限候选可以交给记忆 Agent 进行受限语义重排，重排结果仍需通过 Working Memory 容量准入。高可达但无关的记忆不会进入结果，高度吻合的线索可以激活较低可达但仍存在的记忆。

该子系统的详细设计见[记忆系统设计](docs/memory-system.md)。

## 10. 记忆与认知的交互

记忆在认知决策之前激活，而非仅用于生成对话。

基本流程：

**当前观察进入 Working Memory → 相关意图进入预留容量 → Agent 提交 Retrieval Intent → 混合记忆召回与受限重排 → Working Memory 准入 → 单次 LLM 内联解释、意图权衡与行动决策 → 意图更新、选择性编码与巩固**

记忆激活由查询相关性、当前感知、注意力、意图、既有记忆关联、可达性和抑制共同决定。意图与记忆使用独立类型和生命周期；认知系统拥有意图状态，记忆系统只为其复用召回和 Working Memory 基础能力。

部分激活记忆可以跨认知周期保留，并随着注意力转移退出当前认知状态。

长期记忆不需要在每次认知周期完整加载。

即时编码在认知使用之后、Working Memory 到期之前完成；巩固在配置确定的稳定边界运行。普通模式中必要记忆处理完成并原子提交前，整体模拟不能继续推进。Fast Forward 中只执行确定性维护，所有依赖 LLM 的记忆任务受保护延后，且不能形成或补写离屏主观经历。

## 11. 时间与生命周期

使用统一模拟时钟和配置化固定 Tick 推进世界。单步、普通连续和 Fast Forward 使用相同领域更新语义。

角色和动态物品拥有独立的 Update 逻辑，但不独立推进世界时间。

初期支持手动 Tick、普通连续、零 LLM 的 Fast Forward、暂停、保存恢复及状态检查。

模拟时间不与现实时间强制绑定。

每个固定 Tick 按稳定顺序推进身体、降级行为树、世界过程、世界裁定、感知、认知和记忆维护；本 Tick 新接纳的动作从下一 Tick 开始积累进度。规则解析屏障先于认知屏障，屏障和现实等待期间模拟时间不推进。

当所有运行中的主要实体都禁止认知参与时，系统进入 Fast Forward。快进不跳过 Tick，只取消现实配速并降低展示频率；世界、身体、确定性规则和降级行为树继续运行，但 AI 认知、用户输入解释、记忆 Agent、语义重排、规则生成及其他 LLM 调用全部禁止。非主要实体是否清醒不阻止快进。

主要实体恢复认知资格并形成需求、缺少规则、达到控制上限、收到暂停请求或发生错误时退出快进。若不存在任何能够恢复主要实体的活动过程或外部输入，系统进入明确静止状态而不是无限空转。

不要求每个 Tick 都产生新事件、新目标或对话。

该子系统的详细设计见[时间与整体调度系统设计](docs/time-orchestration-system.md)。

## 12. 配置生成 Skill（Configuration Authoring Skill）

配置生成 Skill 是供 AI Agent 使用的设计时工具，不参与世界 Tick 和运行时模拟。

它的输入和输出均为结构化数据。输入字段可以保存世界观描述、人物小传、对话记录和经历描述等自然语言文本，但每个字段必须已经具有明确且版本化的类型、归属、用途和允许输出。Skill 在字段语义范围内理解自然语言，不接收需要自行猜测用途的任意纯文本，也不要求上游预先把文本拆成最终配置项或记忆痕迹。

Skill 包含两个明确模式。初始配置生成模式产生世界事实、初始状态、角色配置、确定性规则及其他子系统所需的首版候选配置；初始记忆提取模式从明确声明为合格角色经历、对话或世界内记录的字段中产生 Long-term Memory 和主观实体档案候选。两种输出相互分离，人物 Identity 和普通小传不会自动成为角色记忆。

Skill 应识别输入中缺失、冲突或无法确定的内容，只阻塞受影响的候选分区，不把未经确认的推测直接写入候选。生成结果必须保留到输入字段和文本片段的来源关系，并由统一基础设施及对应领域执行权威验证。

Skill 只生产结构化候选和诊断，不负责持久化、用户审阅、批准或应用。候选存储、审阅界面、权威验证编排和正式应用属于独立的后续系统；当前总体设计不提前规定其用户界面。

该子系统的详细设计见[配置生成 Skill 设计](docs/configuration-authoring-skill.md)。

## 13. 第一阶段实验范围

保留小型文本虚构世界、一个正常 AI 角色、一个用户正常角色和少量用于验证行为树及快进语义的降级实体。

仅实现少量地点、物品类型与基础身体能力。

优先验证：

1. 角色能够持续感知并执行跨 Tick 行动。
2. 认知能够在身体动作过程中被新事件唤醒。
3. 不同身体行动能够根据资源占用并行或互斥。
4. 用户能够通过自然语言介入角色当前活动。
5. 角色能够形成并维持个人意图与共同决定。
6. 角色能够基于自身感知形成有限、具有主观特征的记忆。
7. 过去经历能够影响后续认知与行动。
8. 角色能够保持沉默或休息，不因 Tick 推进而强制产生新行动。
9. 世界、人物和身体配置能够由同一基础设施完成组合、引用解析、验证及版本识别。
10. 世界规则和身体效果映射能够复用共享的声明式求值、索引和追踪能力，同时保持各自的状态权限。
11. Working Memory 能够按确定性容量和快速衰减限制当前认知内容，未使用内容不会自动形成持久记忆。
12. Recent Memory 能够选择性巩固为 Long-term Memory，超窗未巩固内容可以真实遗忘且不会从审计归档泄漏回来。
13. 角色能够对实体形成独立、可错误的主观档案，并在感知条件不足时无法仅凭实体 ID 认出对象。
14. 记忆检索能够区分相关性与可达性，并结合结构关联、语义相似度和当前情境形成有限召回。
15. 角色能够保有并召回多条未完成意图，由同一次认知调用自主决定当前行动而非由系统选出目标。
16. 长期未使用意图可以衰减和遗忘，且不会自动转成长期记忆。
17. AI 角色无立即行动时具有受硬上限约束的等待或重审边界，不会因遗漏条件永久失活。
18. 记忆片段解释、意图权衡和行动决定在同一次认知 LLM 调用中完成，不引入独立回忆重建 Pass。
19. Identity 个人历史不会自动成为可检索记忆；只有配置生成 Skill 初始记忆模式的合格来源字段才能形成候选，且仍需记忆验证。
20. 睡眠和昏迷由身体状态与外部刺激逐 Tick 推进，不使用固定时长自动唤醒。
21. 所有主要实体不可认知时进入零 LLM Fast Forward，非主要正常实体不会阻塞或事后补算经历。
22. 降级实体可以在普通和快进模式下通过确定性行为树行动，并接受普通身体及世界验证。
23. Fast Forward 与相同数量手动 Tick 对世界、身体和行为树产生相同确定性结果。
24. 配置生成 Skill 能够从语义明确、值为自然语言的结构化字段生成有来源的首版配置候选，而不会修改持久化状态。
25. 配置生成 Skill 能够分离配置与初始记忆候选，保留缺失、冲突和无法表达诊断，并且不承担用户审阅或应用。

第一阶段实现可配置的轻量身体状态机制，但暂不实现复杂物理引擎、多角色社会、完整生理模拟、大规模世界生成或复杂人格演化。

## 14. 核心设计原则

**角色不是任务执行器，世界不是预设剧情，记忆不是完美数据库，LLM 也不是世界状态的直接控制者。**

系统应允许角色基于个人历史和有限感知形成意图，通过身体与世界实际交互获得反馈，并在不完整、具有个人特征的记忆基础上持续改变未来行为。

最终目标是让角色拥有独立且连续的生活，使用户能够通过自然交流和共同经历，与其逐渐形成独特的伙伴关系。
